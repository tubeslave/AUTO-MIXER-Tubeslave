## Ограниченное правило

`RULE-ML-20261015-0900-01` — `parallel_drum_bleed_send_trim_before_new_processor`:

- **Когда:** parallel drum return заметно увеличивает hi-hat/cymbal wash в snare паузах или между ударами.
- **Менять:** только send snare-top → parallel compression; baseline 0 dB относительно текущего send, проверочная B-точка −3 dB. Число −3 dB — инженерный тестовый шаг проекта, не значение из источника.
- **Не менять одновременно:** threshold/ratio/attack/release, room level, gate, EQ, distortion и общий drum balance.
- **Защитить:** snare punch/body, ghost notes, groove, room depth, cymbal clarity и section intent.
- **Проверить:** raw meters плюс отдельные BS.1770-matched слепые копии; inter-hit 5–12 kHz energy, snare crest/onset, true peak, mono и Дмитрий.
- **Отменить:** bleed не уменьшается, punch/body/ghost notes ухудшаются либо предпочтение исчезает после выравнивания громкости.
- **Confidence:** `medium_low_engineer_specific`; `auto_apply:false`.
