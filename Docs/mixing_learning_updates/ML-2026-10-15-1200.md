### `SRC-ML-20261015-1200-02` — Ableton: Delay Compensation FAQ + How Latency Works

- **URLs:** https://help.ableton.com/hc/en-us/articles/209072409-Delay-Compensation-FAQ ; https://help.ableton.com/hc/en-us/articles/360010545559-How-Latency-Works
- **Глубина:** полностью прочитаны релевантные официальные разделы.
- **Подтверждено:** Live выравнивает пути по максимальной сообщённой задержке; oversampling, convolution, lookahead и спектральная обработка могут добавлять latency. Отключённое устройство может сохранять latency. Есть документированные исключения: отдельная return-to-audio routing topology, monitored tracks при Reduced Latency When Monitoring и экспорт при выключенной Delay Compensation.
- **Ограничение переносимости:** это поведение Ableton Live; конкретный проект Automixer может использовать другую DAW и должен фиксировать собственную конфигурацию.

### `SRC-ML-20261015-1200-03` — Apple Logic Pro: Work with plug-in latencies

- **URL:** https://support.apple.com/en-by/guide/logicpro/lgcpe11997ba/mac
- **Глубина:** полностью прочитан официальный раздел о PDC и Low Latency Monitoring.
- **Подтверждено:** Logic выравнивает channel strips по максимальной latency; latency отдельного plug-in показывается в samples/seconds. Low Latency Monitoring может bypass-ить latency-inducing plug-ins и отключать sends на record-ready tracks; при bounce этот режим не действует.
- **Ограничение переносимости:** platform-specific документация; она подтверждает необходимость фиксировать режим, а не универсальную реализацию всех DAW.

## Пересмотр правила

`RULE-ML-20261015-0900-01` — `parallel_drum_bleed_send_trim_before_new_processor`:

- **Когда:** parallel compression audibly increases cymbal/hi-hat wash in snare gaps and soloed branch comparison localizes the increase to the snare-top contribution.
- **Предусловия:** зафиксировать DAW/version, sample rate, buffer, Delay Compensation/PDC, monitoring/low-latency state, routing graph, processor modes and reported latency. Use the same offline render path for A and B.
- **Менять:** только snare-top send to the existing parallel compressor; A = current send, B = −3 dB. `−3 dB` remains a project test point, not a source value.
- **Не менять:** compressor parameters, plugin modes, oversampling/lookahead, PDC, monitoring, room, gate, EQ, distortion or overall drum balance.
- **Защитить:** snare punch/body, ghost notes, groove, room depth, cymbal clarity, mono compatibility and section intent.
- **Проверить:** preflight path-latency audit; raw offline A/B; separate BS.1770-matched blind copies; inter-hit 5–12 kHz energy, snare onset/crest, true peak, correlation/mono and Dmitry judgement.
- **Отменить:** branch not isolated, routing/PDC state differs, send silently disabled, latency state is undocumented, bleed is not reduced, protected qualities regress, or preference disappears after loudness matching.
- **Confidence:** `medium_low_engineer_specific`; `auto_apply:false`.
