## Result

The queued full text **Improving Inference-Time Optimisation for Vocal Effects Style Transfer with a Gaussian Prior** (`arXiv:2505.11315v2`, WASPAA 2025) and the pinned public implementation were reviewed. The useful result is narrower than the abstract: a Gaussian penalty improves architecture-aligned metrics for a fixed 130-parameter vocal-effects chain, but it is explicitly a weak approximation to a distribution already shown to be non-Gaussian. The listening study leaves only a directional result: after exclusions, 16 participants remained and AFx-Rep plus the prior had the highest mean, but its comparison with the lowest-rated regression baseline was not statistically significant (`Wilcoxon p=.117`). This does not justify a production preset or automatic rule.

### Method actually evaluated

ST-ITO minimizes style-embedding distance between a processed query vocal and a reference. This paper adds `alpha * log p(theta)` where `p(theta)` is a full-covariance Gaussian estimated from 365 inverse-fitted private/Internal DiffVox preset vectors. The authors state that the presets fail multivariate-normal tests and call the Gaussian a weak model that captures only some non-uniformity.

The fixed renderer is the same 130-dimensional minimum DiffVox representation: six-band PEQ, DRC, panner, ping-pong delay and FDN reverb. The prior is unconditional and assumes fixed ordered dimensionality, effects and routing. Mid and side embedding likelihoods are treated as independent.

Objective evaluation starts from 70 MedleyDB vocal tracks, drops five without enough active 11-second segments, splits each remaining track's segments into processed-reference set A and raw-query set B, initializes every method at the prior mean, and runs Adam for 1,000 steps at learning rate 0.01. Metrics are MSS, MLDR and parameter MSE against an inverse-fitted `oracle`, not original engineer controls.

For AFx-Rep, `alpha=0.1` reduced PMSE from 7.756 to 5.168, about 33.4%, while also improving the reported MSS and MLDR deltas relative to the oracle. The best alpha depended on the encoder (`0.1` for AFx-Rep, `1.0` for MFCC); this is calibration evidence, not a universal prior strength. The paper itself notes parameter/audio-space misalignment and approximate symmetries: closer controls need not sound closer.

### Listening test and limitations

The MUSHRA-like test used 19 cross-singer trials of 7–11 seconds, one processed reference and a different raw vocal, plus a hidden raw low anchor. Of 26 responses, eight were removed using a post-hoc 40% low-anchor-identification threshold and two more for unusually large response variation. The final 16-participant analysis reports AFx-Rep highest on average but not significantly different from regression (`p=.117`). The oracle itself was not close to 100 because the fitted effects, true processing and singer timbre differ.

Limits retained:

- no full-mix, masking, rock-section or instrument-role evaluation;
- private/Internal source audio remains unavailable and mostly mainstream Western music;
- Gaussianity is known to be false; the regularizer can shrink rare intentional styles toward the dataset centre;
- alpha was selected from early trials and differs by encoder; no external genre/artist holdout is reported;
- oracle controls are inverse-fit proxies and parameter MSE is non-identifiable under effect symmetries;
- listening exclusions are partly post-hoc, the retained sample is small, and the preference result is not significant;
- fixed topology/order and differentiability exclude variable chains, saturation/modulation and heavy automation;
- no evidence supports copying `alpha`, mean vectors or effect values into the project.

## Knowledge Cards

### `KC-ML-20261012-1800-01` — useful regularizer is not distribution truth

A deliberately misspecified full-covariance Gaussian can still regularize inference-time search, but it must not be described as a faithful vocal-FX distribution. Improvement is conditional on this renderer, preset set, initialization, encoder and alpha.

### `KC-ML-20261012-1800-02` — prior strength is encoder-specific

The best tested alpha changed between AFx-Rep and MFCC. Prior strength is therefore a calibrated algorithm setting, not a transferable mixing parameter or default.

### `KC-ML-20261012-1800-03` — parameter recovery is not perceptual identity

PMSE uses an inverse-fitted oracle and the paper observes approximate parameter symmetries. A lower PMSE can support debugging but cannot substitute for audio-distance checks and loudness-matched listening.

### `KC-ML-20261012-1800-04` — subjective claim is directional only

The retained 16-listener test suggests a ranking but reports `p=.117` for AFx-Rep versus regression. Store this as inconclusive preference evidence, not confirmation of superiority.

### `KC-ML-20261012-1800-05` — centre bias needs an outlier gate

An unconditional Gaussian can penalize valid rare or section-specific styles. Any project experiment must report in-distribution and deliberately outlying target strata separately and cancel the rule if the prior improves centre cases while damaging intentional outliers.
