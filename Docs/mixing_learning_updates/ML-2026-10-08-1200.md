## Sources actually read

### SRC-ML-20261008-1200-01 — ITU-R BS.1770-5

- title: *Algorithms to measure audio programme loudness and true-peak audio level*
- publisher/date: ITU-R, `2023-11`
- URL: https://www.itu.int/rec/R-REC-BS.1770-5-202311-I/en
- free PDF: https://www.itu.int/dms_pubrec/itu-r/rec/bs/R-REC-BS.1770-5-202311-I!!PDF-E.pdf
- reading depth: `full_normative_scope_annex1_loudness_algorithm_annex2_true_peak_and_validation_limitations`
- source type: `official_standard_primary`

The loudness path uses K-weighting, channel-wise mean-square energy, channel weighting and 400 ms blocks with 75% overlap. Integrated loudness uses an absolute gate at −70 LKFS/LUFS and a relative gate 10 dB below the absolute-gated result. The standard warns that the result estimates subjective loudness and retains programme/listener/listening-condition uncertainty. True peak estimates continuous-time peaks that may lie between samples; for 48 kHz the guideline uses at least 4× oversampling and reports dBTP. This is standards evidence for the loudness and true-peak parts of the contract, not for a crest-factor target.

### SRC-DYN-20260913-201140-01 — EBU Tech 3341 v4 (updated existing card)

- URL: https://tech.ebu.ch/docs/tech/tech3341.pdf
- reading depth upgraded to: `full_document_sections_1_3_including_time_scales_gating_LRA_true_peak_compliance_and_interpretation`

EBU Mode defines momentary loudness as an ungated 0.4 s sliding rectangular window, short-term loudness as an ungated 3 s sliding rectangular window, and integrated loudness using the BS.1770 gate. LRA must be flagged unstable during the first 60 s after reset. EBU Mode requires Programme Loudness, LRA and Maximum True Peak; it does not define crest factor.

### SRC-DYN-20260913-201140-02 — EBU Tech 3342 v4 (updated existing card)

- URL: https://tech.ebu.ch/docs/tech/tech3342.pdf
- reading depth upgraded to: `full_document_algorithm_compliance_reference_implementation_and_limitations`

LRA is the 95th minus 10th percentile of a distribution of 3 s short-term loudness values after −70 LUFS absolute gating and −20 LU relative gating. It is a macroscopic variation descriptor designed to resist single loud events and fades. The document explicitly says it must not be confused with crest factor or other dynamic-range measures; very short or isolated-utterance programmes can yield misleadingly high LRA.

## Revised Knowledge Card

### KC-ML-20261008-0900-01 — measurement-contract split

Revised claim: `crest factor`, `peak-to-loudness`, and `LRA` are different families. Mathematical crest factor requires peak/RMS under one fixed window and channel rule. A difference between dBTP and LUFS is a peak-to-loudness descriptor whose loudness window/gating must be named; it is not automatically crest factor. LRA uses the EBU percentile/gating algorithm and is unsuitable for event attack. Confidence: `high` for standards definitions; `medium` for the project-local peak-to-loudness diagnostic; `low` for any numerical transfer from vendor examples.
