## Outcome

The two highest-priority sources from the 15:00 search were read again at full-text depth and checked against their public artifacts. The useful result is mostly constraint, correction and experiment design:

1. PEACE is retained only as a research shortlist/reranking candidate inside its known 21-effect serial Faust library. It is not evidence for exact parameter recovery, unknown-plugin identification, dynamics estimation, stereo-direction recovery, parallel/feedback topology, or mix quality.
2. The numerical record for PEACE is corrected: arXiv v1 contains minor corrections/clarifications relative to the camera-ready paper, and the repository says RIR/chain numbers differ because the proceedings path used reflection padding while the arXiv path uses the training-time zero padding. These are versions of one work, not independent confirmation.
3. A supervised closed-set classifier outperformed PEACE retrieval on the reported 420 ordered-pair benchmark. Any project evaluation must therefore include a simple closed-set baseline rather than presuming retrieval is superior.
4. CTAG-FX evidence remains split: the processor-side prompt/scramble test and the synth-side A&R-versus-CTAG CLAP test are different evaluations. They do not form an end-to-end proof of perceptual or semantic validity.
5. The official CTAG-FX demo exposes one normalized 78-D configuration, but its “RAW” guitar has already passed through EQ, 1176, EQ73 and LA-2A stages, and the demo explicitly warns that processed outputs are louder. It is not a valid controlled bypass A/B for the project.
6. No rule is promoted. All candidate rules remain auto_apply:false; both new/revised experiments remain not_run_blocked. The next executable project experiment is unchanged: EXP-ML-PENA-AB15-LISTEN-20261010-1800.

## Sources actually read

### SRC-ML-20261016-1500-01 — PEACE

- Primary text: https://arxiv.org/abs/2610.03405 and full arXiv HTML
- Depth: full_text_re_read_plus_results_tables_and_limitations
- Publication status: accepted at ISMIR 2026; arXiv v1
- Version correction: the arXiv record states that v1 contains minor corrections and clarifications relative to the camera-ready version.
- Dataset/protocol:
  - 200,000 training, 8,192 validation and 4,096 test examples;
  - 21 Faust effects in serial chains of length one to three;
  - 10 s, 48 kHz audio, wet signal normalized to −18 LUFS;
  - train/validation source material from 23 public datasets and test material from four named datasets;
  - randomly sampled parameters and source/preset pairings; the source is not guaranteed to be genuinely dry.
- Retrieval results:
  - single-effect, gallery 1,024: BoxGraph R@1 16.8%, R@10 44.3%; T5 R@1 18.1%, R@10 45.2%;
  - weak classes include compressor (2.5/2.6% R@1), gate (0.3/0.1%), limiter (0.5/0.2%) and stereo width (0.2/0.2%);
  - exact ordered-pair retrieval on the 420-pair benchmark: BoxGraph R@1 17.4%, R@10 61.4%; T5 12.4%/43.2%;
  - the supervised classifier reached R@1 21.4% and R@10 65.9%.
- Bounded conclusion:
  - R@10 61.4% means the true ordered pair is absent from the top ten in 38.6% of benchmark cases even under the matched synthetic library;
  - a fixed small gallery may favor a classifier, so PEACE must pass a closed-set baseline gate;
  - stronger T5 long-chain retrieval beyond the training length remains same-library synthetic evidence, not transfer to real plugins or unknown graphs;
  - the out-of-domain test is limited to RIR/reverb behavior;
  - no listener study was reported.
- Correction to prior report: “no correction or later version found” is withdrawn. The arXiv version is now canonical for numerical evidence; the camera-ready version remains the same evidence family.
- Citation check: partial; no independent replication or correction notice beyond the authors’ version note was established.

### SRC-ML-20261016-1500-02 — CTAG-FX

- Primary text: https://arxiv.org/abs/2610.08182 and full arXiv HTML
- Official demo: https://taylor3527eg-hub.github.io/ctag-fx-platform-demo/
- Depth: full_text_re_read_plus_method_results_demo_and_provenance_audit
- Method/protocol:
  - 78 synthesizer parameters are heuristically mapped to processor controls;
  - the tone-shaping test bypasses A&R-CTAG: GPT-4o generated ten configurations for each of four prompts;
  - one 10 s clean-guitar performance was used with 30 shared scrambled permutations per prompt;
  - role/scramble analysis used RMS matching, spectral differences, harmonic energy, H6–H10 and crest measures;
  - 28 of 1,200 scrambled renders were excluded after nonfinite output;
  - A&R-versus-CTAG is a separate synthesizer-side CLAP comparison across ten prompts, not an end-to-end CTAG-FX test;
  - reported mean final CLAP score was 0.7545 for A&R and 0.6166 for CTAG, without listener validation;
  - the CTAG-FX matching is RMS-based, not full BS.1770 loudness plus true-peak matching;
  - NAM captures covered eight fixed configurations and reported ESR 0.0003–0.0815, median 0.0140, but no perceptual equivalence or arbitrary-configuration generalization study.
- Demo audit:
  - code release is still marked “coming soon”;
  - exact normalized values for at least one 78-D synthesizer configuration are exposed;
  - “RAW Input” is documented as already processed by Channel EQ, UA 1176, T-Racks EQ 73 and Teletronix LA-2A;
  - the page warns that processed outputs are louder and are not loudness matched.
- Bounded conclusion:
  - public configuration visibility partially resolves parameter provenance but not renderer reproducibility;
  - processor mapping, stabilizer implementation, dependency lock, license and executable code remain unavailable;
  - demo audio cannot serve as a one-factor project bypass A/B;
  - CTAG-FX listener evidence is still absent; the paper describes a user study as future work.
- Citation check: partial; no independent replication was established.
