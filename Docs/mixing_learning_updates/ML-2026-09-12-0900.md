## What is genuinely new

The drum-editing model now separates **sample onset**, **transient/envelope shape**, and **perceived event time**. A separator can preserve detected onset positions while changing attack slope, crest and dynamic variation; psychoacoustic work shows that attack and duration help determine a sound's perceptual centre. Phase/timing proposals therefore need transient and envelope quality-gates, not only SDR, waveform peak or onset-F.

A second guardrail is DAW-specific: ordinary multi-track AudioWarp quantization does not preserve phase coherence by default. Cubase 15 provides a separate Phase-Coherent AudioWarp mode with equal-start/equal-length and common-marker requirements. Slice-based Group Editing remains the lower-assumption baseline.

## Sources actually read

### Beyond SDR: rhythm-critical fidelity after separation

- Full paper: https://arxiv.org/html/2609.04224
- DOI: `10.48550/arXiv.2609.04224`; the submission page reports 12 July 2026.
- Reproducible code/results: https://github.com/dingchuxin/MSS_drum_fidelity_eval (MIT).
- Read depth: full HTML method, results, limitations and code availability; repository README and license.
- On MUSDB18-HQ drums, onset-F correlated with SI-SDR (Spearman ρ = +0.62), while correlations between SI-SDR and attack/dynamic distortions were weak (|ρ| ≤ 0.29). Two SDR-matched frontier models differed by more than 2× in the paper's attack-slope distortion statistic.
- Input context altered transient/dynamic rendering more than onset positions. The transformer-vs-CNN attack-drift result was marginal (paired p = 0.044; n = 20) and fragile under leave-one-out analysis.
- Limits: one checkpoint per architecture, MUSDB18-HQ bias, no listening test linking measured attack change to perceived timing, drums-centred analysis. This supports a quality gate, not a universal separator ranking.

### Perceptual centre is not waveform onset

- Metadata/abstract: https://pubmed.ncbi.nlm.nih.gov/30802130/
- DOI: `10.1037/xhp0000611`.
- Read depth: abstract and accessible author-manuscript preview, not the publisher version in full.
- Danielsen et al. found attack and duration to be primary cues for P-centre location and variability. Fast/short sounds produced narrow early timing distributions; slower/longer sounds produced broader timing regions.
- Bounded implication: an edit that keeps the same onset but reshapes attack can still change perceived timing. No millisecond preset is derived.

### Groove does not force one universal amount of correction

- Full article: https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2016.01487/full
- DOI: `10.3389/fpsyg.2016.01487`.
- Read depth: full methods, manipulation design, results, discussion and limitations.
- Senn et al. scaled performed bass/drum microtiming in 20-second funk and swing excerpts. Fully quantized and original-performance versions received similarly high self-reported groove ratings; exaggerated deviations reduced ratings. Experts were more sensitive.
- Limits: two performances, funk/swing rather than rock, and subjective ratings did not consistently agree with measured body movement. This rejects both “always quantize” and “never quantize” as universal rules.
