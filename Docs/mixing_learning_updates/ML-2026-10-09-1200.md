## Knowledge Cards

### KC-ML-20261009-1200-01 — render duration and inference crop are separate provenance fields

A 10-second render corpus and a model documented as trained on 6-second excerpts are not contradictory if crops were used, but the crop rule is not documented in the materials read. Project evaluation must record both source-render duration and exact model-input crop/offset. Confidence: `high_documentation_gap`.

### KC-ML-20261009-1200-02 — preprocessing removes cues relevant to mixing

The released frontend normalizes loudness, caps peaks, converts L/R to mid/side and uses log-mel magnitude features. Retrieval therefore cannot be treated as evidence about absolute level, true peak, L/R direction, waveform phase or transparent dynamics. Confidence: `high_source_code`.

### KC-ML-20261009-1200-03 — inference-contract tests are not metric reproduction

The public tests provide useful shape, serialization, masking and parser guards, but they do not demonstrate the paper's Recall@K with released weights. A successful unit suite would still leave checkpoint identity, metric parity and domain transfer unverified. Confidence: `high_repository_audit`.

### KC-ML-20261009-1200-04 — topology masking needs one target definition

Parameter-visible exact-program retrieval and parameter-masked topology retrieval answer different questions. A controlled comparison must hold the topology target, query set and gallery fixed, then change only parameter visibility. Confidence: `high_task_definition`.

### KC-ML-20261009-1200-05 — dependency and weight licences are separate gates

MIT code does not remove the non-commercial terms of released weights or the mixed terms of renderer sources. Use of the pretrained model and redistribution of generated/self-contained DSP sources require separate licence review. Confidence: `high_primary_notices`.
