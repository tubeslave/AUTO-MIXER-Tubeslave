## Deep-review result

The full DAFx26 compressor-control paper was re-read against its public dataset and the current public `torchcomp` implementation. The main scientific conclusion survives but its reproducibility and generalisation boundary is narrower than the search card implied.

The Hugging Face automatic viewer exposes one `train` split with 40,577 rows. Those rows are flattened files from the AudioFolder tree, not 19,710 paired input/output/control examples. A valid experiment must join the documented metadata tables and must never split the viewer rows or `metadata_main` rows randomly.

The public `torchcomp` main branch is a dependency, not the paper implementation. Stock code uses an RMS detector; the paper replaced it with a peak detector driven by the maximum instantaneous stereo amplitude and one shared gain trajectory. No public patch or parity commit for that modification was found. The proposed A/B therefore remains blocked.

## Source Card update

### SRC-ML-20261014-0900-01 — method, calibration and generalisation audit

- **Primary sources:** <https://www.dafx.de/paper-archive/2026/papers/DAFx26_paper_30.pdf> · <https://arxiv.org/abs/2606.18573>
- **Reading depth:** full paper re-read, including dataset construction, calibration, modelling, optimisation and limitations
- **Citation check:** `partial`; no independent replication or correction found

Confirmed method details:

- 10 models per loss regime; one 30-second example per model; five hardware permutations; at most one excerpt per song; identical examples across loss regimes.
- 3,000 Adam steps at learning rate 0.01 with plateau reduction. Fitting and evaluation use the same example by design; this isolates objective sensitivity and does not test generalisation.
- The paper model uses a peak detector and a single gain applied to both channels. It is restricted to 10:1 and fixed release because the stock hard-knee/single-pole structure does not represent lower-ratio curvature or AUTO release accurately.
- Waveform loss is preceded by the stated DC blocker `H(z)=(1-z^-1)/(1-0.995z^-1)`.

Confirmed dataset/calibration details:

- 219 stereo 30-second clips × 90 hardware permutations = 19,710 paired examples. One random excerpt is taken per source file, resampled to 44.1 kHz, faded for 10 ms at each boundary and peak-normalised to 0.9.
- Hardware is a serviced and calibrated 1991 SSL Logic FX G384. The measured control voltage comes from one VCA; a common control is used for both channels apart from a small calibration scalar.
- Calibration covers the static curve, attack/release/AUTO bursts and MLS alignment. Input/output audio is aligned within one sample, but the measured control trajectory can require a separate integer or fractional lag chosen by minimising the output reconstruction error.
- Static gain not explained by the control voltage is removed and stored as metadata. Effective threshold is derived from the measured onset above baseline variation and is not interchangeable with the front-panel or ideal-model threshold.
- The paper's threshold/makeup augmentation is a dataset protocol: a common input/output gain offset can emulate threshold changes while preserving the control trajectory. It is not a mix preset and requires explicit clipping/headroom guards.
