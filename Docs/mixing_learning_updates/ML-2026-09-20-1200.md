### AUDIT-ML-20260920-1200-01 — fyp-clean2fx implementation

- Репозиторий: https://github.com/oliveriobp/fyp-clean2fx
- Ревизия: `b6c20ba2966564282fe7a666ad3dc915da883c79`
- Проверены: пять notebooks, README, `.gitignore`, smoke-test и `website/inference.py`.
- `reading_depth`: `full_static_notebook_and_inference_audit`
- `executed`: `false`

Ключевые наблюдения:

1. `AugmentedPairDataV3.__getitem__` строит план детерминированно из `seed + idx`, но каждый индекс выбирает события из общего `keys_by_pair`. `random_split(..., seed=0)` делит индексы, а не исходные ноты/пикапы/записи. Поэтому source-level independence не обеспечена.
2. Все training notebooks используют тот же 90/10 split. `test_loss` передаётся в `ReduceLROnPlateau` каждый epoch, после чего evaluation notebook оценивает тот же split. Отдельного validation и untouched test нет.
3. Evaluation выбирает первые 20 доступных примеров каждого из десяти эффектов из одного split: 200 из 4,457 test indices. Повторных split/seeds, bootstrap CI или uncertainty нет.
4. Clean и target magnitude делятся на `max(clean_spec, target_spec)`. Масштаб входа тем самым зависит от неизвестного target. В deployment-коде это заменено hard-coded effect-specific correction, оценённой на 50 training samples; этот causal path не входит в headline benchmark.
5. Для FAD target, unchanged baseline и все predictions независимо проходят 32-iteration Griffin–Lim и затем отдельную peak normalization. FAD не видит исходный gain/energy ratio и одновременно включает ошибку phase reconstruction.
6. Показатель `OVERALL` — среднее effect means. Для ConvVAE ratio-of-means даёт `+20.8%` MSE improvement, хотя ConvVAE хуже unchanged baseline для 9 из 10 эффектов. Единственный RAT (`0.003216 → 0.001096`) более чем полностью создаёт положительный aggregate; без RAT направление меняется.
7. README называет девять CSV «source of truth», но `eval_exports/` исключён `.gitignore` и в ревизии отсутствует. Доступны только embedded notebook outputs; cache, dependency lock и корневая лицензия отсутствуют.
8. Smoke-test проверяет paths/cache/first batch/checkpoint loading, но не воспроизводит training, таблицы, causal normalization, safety, audio equivalence или listener results.

## Пересмотр прежних выводов

- **Было:** 200-example held-out benchmark. **Теперь:** это 200 выбранных примеров из split, который одновременно служит scheduler-validation; underlying note pool общий с train. Термин `independent held-out test` не применяется.
- **Было:** U-Net improves MSE/FAD relative to unchanged clean. **Уточнение:** это верно только внутри target-aware normalization + magnitude/Griffin–Lim/peak-normalized protocol. Production causal path отдельно не проверен.
- **Было:** ConvVAE не даёт устойчивого выигрыша. **Теперь:** это подтверждено сильнее: 9/10 per-effect MSE хуже baseline, несмотря на положительный ratio-of-means aggregate из-за RAT.
- **Было:** framework добавляет energy-control gate. **Уточнение:** текущий FAD path принципиально не способен проверить этот gate после per-file peak normalization.

## Knowledge Cards

1. `KC-ML-20260920-1200-01`: нормализация входа по максимуму clean+target использует недоступную на inference информацию и должна считаться oracle path.
2. `KC-ML-20260920-1200-02`: effect-specific correction из 50 training samples — отдельная deployment heuristic; её нельзя считать эквивалентом benchmark normalization без A/B.
3. `KC-ML-20260920-1200-03`: index-level random split синтетических композиций не обеспечивает независимость исходных нот/пикапов между train и test.
4. `KC-ML-20260920-1200-04`: split, управляющий scheduler, является validation; итоговый test должен быть отдельным и использован один раз.
5. `KC-ML-20260920-1200-05`: 20 examples/effect из одного split без CI не дают оценки sampling uncertainty.
6. `KC-ML-20260920-1200-06`: per-file peak normalization перед FAD стирает gain/energy differences; raw-level gates нужны отдельно.
7. `KC-ML-20260920-1200-07`: FAD по независимо Griffin–Lim-реконструированным файлам смешивает качество magnitude model и phase reconstruction.
8. `KC-ML-20260920-1200-08`: original-waveform, unchanged-through-same-reconstruction и deterministic-processor baselines должны быть раздельными.
9. `KC-ML-20260920-1200-09`: ratio-of-means может скрывать ухудшение большинства эффектов; нужны sign count, per-effect table и sensitivity without dominant class.
10. `KC-ML-20260920-1200-10`: positive ConvVAE aggregate не является общим выигрышем: RAT доминирует, а 9/10 эффектов хуже baseline.
11. `KC-ML-20260920-1200-11`: embedded notebook outputs без опубликованных CSV, cache и pinned dependencies дают только partial reproducibility.
12. `KC-ML-20260920-1200-12`: SFX identity rating, исключающий loudness, не заменяет raw safety, музыкальное качество или blind preference in mix.
