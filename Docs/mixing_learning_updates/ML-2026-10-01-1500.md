## New scientific source card

### SRC-ML-20261001-1500-01 — ADAC: differentiable graph to real-time DSP compilation

- **Stable IDs:** `arxiv:2606.21277v1`; title-normalized `compiling-differentiable-audio-graphs-to-real-time-dsp`.
- **Primary text:** https://arxiv.org/pdf/2606.21277
- **Author code:** https://github.com/cucuwritescode/adac
- **Publication / discovery:** arXiv v1 dated `2026-06-19`; DAFx-26 demo proceedings, `2026-09-01..04`; discovered `2026-10-01`.
- **Reading depth:** `full_text_plus_author_readme`; all four pages, equations, correctness/cost/stability sections, conclusion, README and repository licence read. Source was not installed, compiled or benchmarked here.
- **Method:** traverse a trained PyTorch/FLAMO graph, serialize topology and effective/raw parameters to a JSON IR, emit FAUST, then target plugins/web/embedded/FPGA. The demonstrated vocabulary covers series, parallel and recursive composition with delay, gain/matrix and filter leaves.
- **Verification reported by authors:** emitted FAUST and source-model impulse responses agreed within `7e-5` of peak without alignment for tested FDN paths; the repository reports 201 unit tests plus integration IR comparisons. A 32-line FDN ran about 90× real time and a 64-line FDN about 14× on one Apple M2 core at 48 kHz. These are author results, not reproduced here.
- **Safety contribution:** stability is checked after decimal formatting and single-precision casting. A small-gain condition over each loop and pole checks are used; the exporter refuses unstable or unproven graphs unless explicitly overridden. Spectral radius alone is rejected as insufficient once filters or non-normal matrices are involved.
- **Controls:** RT60 uses homogeneous decay `g_i = 10^(-3 m_i/(f_s RT))`; dry/wet and pre-delay are also exported as macro-controls. These are implementation formulas/controls, not recommended rock settings.
- **Reproducibility:** public MIT repository, documentation and tests are present; repository status is `beta`. No local execution was performed.
- **Limits:** demo/conference paper; evaluation centers on linear time-invariant FDN/SDN cases. Fractional delays are rounded to nearest sample in the paper's evaluated path. Equivalence and stability arguments do not yet cover nonlinear/time-varying processors; leaf coverage and a stable IR specification remain open.
- **Bounded conclusion:** useful as a future research-branch export gate. It does not validate an audible improvement, a learned mix, or automatic deployment into the project.
