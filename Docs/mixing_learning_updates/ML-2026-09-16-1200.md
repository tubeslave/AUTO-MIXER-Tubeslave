## Outcome

The search-run distinction between tonal normalization, spectral overlap and masking survives deeper review, but it needs two corrections.

First, Hafezi–Reiss does not use a calibrated auditory model as its controller. It explicitly substitutes an engineering-inspired masking heuristic because earlier auditory-model measures were costly and had behaved inaccurately on multitrack music. Second, the current Automixer `EQNormalizer` is not an implementation of that paper: it analyzes one signal against a fixed target curve, whereas Hafezi–Reiss compares all tracks pairwise and attenuates a masker where another track has an essential region. The citation in the module is therefore contextual, not implementation provenance.

## Sources actually read

### Hafezi & Reiss — Autonomous Multitrack Equalization Based on Masking Reduction

The complete 12-page JAES paper was read: model, four implementations, parameter choices, objective evaluation, listening procedure, results, limitations and appendix. Stable base source: `jaes_hafezi_reiss_masking_eq`; deep-review card: `S-ML-20260916-1200-01`. [DOI](https://doi.org/10.17743/jaes.2015.0021) · [institutional metadata](https://qmro.qmul.ac.uk/xmlui/handle/123456789/7804) · [legally accessible reading copy](https://scispace.com/pdf/autonomous-multitrack-equalization-based-on-masking-31dej53ans.pdf)

What the method actually does:

- Every track is evaluated as a possible masker against every other track: `K(K−1)` pairs. Relative track levels are assumed already correct; stereo inputs are converted to mono for analysis.
- A frequency is actionable when the masker is louder there and the region is ranked essential for the maskee but nonessential for the masker. The detector omits cases where a quieter masker still raises the maskee's audibility threshold.
- Offline versions average non-overlapping 1024-point FFT spectra over the full excerpt and use up to three second-order IIR cuts per track. The published `RT=10`, `Q=2` and strength behavior came from informal listening, not a general psychoacoustic calibration.
- Real-time versions use ten octave-band RMS measurements, EMA smoothing and up to five time-varying peaking filters. The constrained variant used `Q=5` and a maximum `6 dB` attenuation; those values belong to this implementation and are not adopted as Automixer presets.

Evaluation boundaries:

- Eight excerpts, 4–10 tracks and 15–50 seconds, covered several genres including one rock excerpt. The raw sum and four systems were compared objectively; reported mean MUR improvements were only `0.6%`, `2.4%`, `1.1%` and `4.2%` by implementation, with some songs getting worse.
- Eleven participants completed a headphone multistimulus test; two were excluded by an identical-stimulus error rule, leaving nine. The mixes were loudness-normalized, but the design had no fixed reference or low anchor and forced at least one rating below 20 and one above 80. The authors note that this may exaggerate differences.
- More objective masking reduction did not consistently produce a more preferred mix. The unconstrained real-time version improved the objective measure but failed the subjective masking task; the authors themselves call the metric potentially ill-suited for multitrack music.
- Conclusions are therefore evidence for bounded cross-adaptive candidates and loudness-matched listening, not for automatic deployment or universal `Q`/gain settings.

### Välimäki & Reiss — All About Audio Equalization: Solutions and Frontiers

Relevant sections of the 47-page peer-reviewed review were read in full: FIR/linear-phase design, dynamic EQ, masking/noise-based EQ, autonomous/targeted equalization and the conclusions/table of trade-offs. Card: `S-ML-20260916-1200-02`. DOI `10.3390/app6050129`. [Open publisher PDF in Aalto repository](https://acris.aalto.fi/ws/portalfiles/portal/9936551/applsci_06_00129.pdf)

Bounded findings:

- Linear-phase FIR can preserve phase relationships for a chosen magnitude response, but it adds latency and may create pre-echo/ringing around transients. Minimum-phase IIR is recommended for low-latency/live use; neither topology is universally better sounding.
- Dynamic EQ adds threshold, attack and release to a time-varying EQ curve. It must not be treated as a synonym for static matching or a generic multiband compressor.
- A targeted real-time equalizer described in the review first applies a hysteresis activity gate, then smooths both the desired response and the applied filter from frame to frame. These are guardrails against learning silence/noise and against coefficient chasing.
- The review characterizes Hafezi–Reiss results as mixed and needing improvement. Its source-code link was checked but timed out, so reproducibility verification is partial.

## Read-only implementation audit

Inspected [`backend/ml/eq_normalization.py`](https://github.com/tubeslave/AUTO-MIXER-Tubeslave/blob/master/backend/ml/eq_normalization.py), its unit tests and the existing source/rule registry. No code was changed.

The module citation says it is based on Ma et al. and Hafezi–Reiss, but the executable behavior is materially different from Hafezi–Reiss:

- it accepts one 1-D signal and has no cross-track `K(K−1)` analysis, masker/maskee roles or essential-region comparison;
- it averages power spectra over non-overlapping Hann-windowed frames, compares the result with hand-authored fixed curves and fits up to six fixed-center bands;
- it has no activity gate, temporal state/smoothing, loudness calibration, section labels or psychoacoustic/cross-adaptive masking measure;
- its output is only an EQ command profile, so filter realization, phase topology, latency and audible result are not tested here;
- unit tests check shape, fallback, clamping and serialization, not source-grounded equivalence, target provenance, silence behavior, phase response or musical preference.

This is not evidence that the module is defective; it establishes that it should be described as **single-track static spectral-profile correction**, not as a validated implementation of autonomous multitrack masking reduction. The existing active rule `masking.problem_outliers_only` also inherits only bounded support: the paper supports prioritizing the strongest detected events within its own heuristic, but not the current global `−3…+2 dB`, `Q 0.7…4` bounds or automatic musical validity.

## Conclusions revised

1. **“Masking model” narrowed.** Hafezi–Reiss uses an engineering heuristic and compares it against MUR; neither is established as a ground-truth musical masking metric.
2. **Static/dynamic choice clarified.** Persistence is a project decision rule. The literature supports explicit time variation, gating and smoothing, but does not prove that every intermittent collision should receive dynamic EQ.
3. **Phase separated from magnitude.** Equal-magnitude EQ candidates can differ in latency, group delay and transient behavior; “linear phase” is not an automatic quality upgrade.
4. **Target matching kept subordinate to preference.** The already indexed semantic-EQ study `SRC-ML-20260912-1800-01` found untouched references preferred over both predicted and oracle target matching in its small test. Better target fit is not sufficient evidence of a better mix.
5. **Implementation claims require traceability.** A paper cited in a module docstring is not evidence that its analysis graph, constraints or evaluation were implemented.
