## Outcome

One fresh preprint was found and read in full: Aura, a controllable mono-to-stereo upmixer using a pretrained flow prior and a reward over ERB-band inter-channel coherence (IC) and inter-channel level-difference (ILD) distributions. The paper is useful for a bounded research hypothesis, not a production rule. Its evaluation uses 200 disjoint five-second, vocal-removed MUSDB18-HQ test excerpts; Aura is not mono-preserving by design, the generative restoration setting loses substantial mid-signal fidelity, and the double-blind listening test has only five participants. Aura-Small outperforms the paper's baselines on Spatial FD and IC distance, but Aura-Medium is worse on all reported spatial metrics, so model scale is not a monotonic quality proxy.

The paper's width control changes the target coherence with `kappa`, while its spatial reward matches one reference excerpt's IC and ILD distributions. That supports a one-factor, human-gated research comparison only after measurement consistency is established. It does not justify widening existing stereo mixes, processing vocals, choosing a universal reference, or automatically accepting a render from objective spatial metrics.

One new YouTube video was content-read through its permitted companion transcript: Andrew Scheps' explanation of parallel compression. The transcript supports a source-specific workflow—keep the dry transient path, blend a heavily compressed return, feed multiple related elements when that avoids recovery gaps, follow the main pan, and judge the return in the full mix. It provides no numeric settings and no loudness-matched controlled comparison. Two rediscovered videos were removed as duplicates because they were already fully studied.

No new rights-clear raw multitrack or reference was verified. No audio was downloaded, played, analyzed or uploaded. No code, model, plug-in, Job, GPU or external Space was run. No DSP, runtime rule, repository implementation, model or audio asset was changed.

### SRC-ML-20261018-1500-01 — Controllable Mono-to-Stereo Upmixing using Reward-tilted Flows

- Stable ID: `arxiv:2610.15967v1`
- DOI: `10.48550/arXiv.2610.15967`
- Authors: Sattwik Basu, Gautam Bhattacharya, Alan Seefeldt.
- Affiliations disclosed in the paper: UIUC and Dolby Laboratories; the first author's work was done during a Dolby internship.
- Submitted: 2026-10-11.
- Canonical URL: https://arxiv.org/abs/2610.15967
- Full text: https://arxiv.org/html/2610.15967v1
- Official demo link: https://basusattwik.github.io/aura-demo/
- Reading depth: `full_text_complete_methods_equations_experiments_results_discussion_appendix`.
- Publication state: `preprint`; licence reported on the public record as CC BY 4.0.
- Method: posterior sampling with Stable Audio 3 as a 44.1 kHz latent stereo prior; measurement-consistency refinement is separated from reward refinement. The reward fits per-ERB-band IC to Beta distributions and ILD to Gaussian distributions, then minimizes closed-form KL divergences to a single reference excerpt.
- Width steering: `rho_target <- 1 - kappa * (1 - rho_target)`. `kappa=1` leaves the reference coherence mean unchanged mathematically; this is parameter provenance, not a validated project default.
- Paper inference schedule: native eight flow steps, 15 measurement-consistency and five reward-refinement iterations per step. These are paper settings only.
- Evaluation: 200 disjoint five-second MUSDB18-HQ test excerpts at 44.1 kHz, vocals removed and peak-normalized to -0.5 dBFS, with explicit activity/crest/side-energy/spectral filters.
- Objective result: Aura-Small reports Spatial FD 20.3344 and IC distance 0.1693, best among the listed systems on those columns; it is not mono-preserving, and FlowDPS is slightly better on ILD distance. Aura-Medium is slightly better on MR-STFT/SI-SDR but worse than Small on every reported spatial metric.
- Restoration trade-off: for clipped observations the reported full-band mid SI-SDR drops from 17.73 dB for the degraded input to 6.74 dB for Aura while spatial metrics improve. This is evidence of a fidelity/spatial trade-off, not transparent restoration.
- Listening test: double blind, five participants, eight excerpts, six conditions, randomized presentation, continuous 0–100 quality and image ratings. Aura's reported mean spatial score is 67.4 and quality score 61.8; the dual-mono anchor scores 70.0 on quality and 16.7 on image. No inferential statistics or confidence intervals are reported in the visible full text.
- Limits: small listener sample; filtered vocal-free five-second test domain; no declared independent replication; no production-length evaluation; no uncertainty analysis; no per-genre or per-instrument result breakdown; known forward operator required; model/computational dependence; objective metrics partly reuse the same cue family as the reward.
- Artifact status: an official audio-demo page is linked, but it was not retrievable by the current reader; no official Aura code repository, frozen environment, checkpoint manifest or executable licence was found in targeted search. Nothing was run.
- Bounded conclusion: Aura motivates a shadow-only experiment on rights-cleared mono material with strict downmix/content, stereo, transient and human-listening gates. It does not establish an automatic stereo-width processor.
