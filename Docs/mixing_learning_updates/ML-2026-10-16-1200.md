## Итог

Углублённо проверены два приоритета утренней очереди:

1. полный релиз данных Opus listening study;
2. закреплённые исходники `vst-bench-ml` и companion host.

Главные исправления:

- «160 kbps» в Opus-работе — целевая настройка unconstrained VBR, а не фактический постоянный битрейт: у восьми Phase-2 фрагментов опубликованные средние значения составляют **159–213 kbps**;
- Phase 2 использует BLUP-selected critical listeners/material из Phase 1, а не независимо набранную экспертную панель и независимый материал;
- опубликованные CSV позволяют проверить состав и описательные числа, но без analysis script, stimuli/encoded files и trial/session/order полей точное воспроизведение LMM/TOST и screening остаётся неполным;
- core `vst-bench-ml` доказывает внутреннюю целостность manifest/artifacts, но complete kept-attempt ledger, per-attempt readback и reset evidence добавляются только companion workflow для синтетического fixture;
- стандартный render path удаляет raw WAV и сохраняет loudness-normalized NPZ; для dynamics, gain, clipping и stereo исследований это нельзя использовать как единственную аудиокопию;
- silence/clip QC в core сводит stereo к среднему mono, поэтому противофазный или асимметрично клиппующий stereo-выход может быть оценён неверно.

Ни одно из этих уточнений не меняет DSP/runtime и не превращает исследование в auto-apply правило.

#### Подтверждённые границы

- Core manifest связывает software/environment/plan/output hashes, records и drop/failure ledger, но не аутентифицирует происхождение.
- Core client проверяет объявленные host capabilities до рендера; complete attempt trace/readback/reset proof относится к companion fixture validation.
- Public companion host принимает только конкретный self-authored Method Fixture по locked UID/name/vendor/parameter count/SDK identity.
- Fixture — MIDI instrument без audio input; он выдаёт одинаковый mono-сигнал в L/R, записанный как 16-bit stereo WAV при 44.1 kHz.
- Expected outputs охватывают четыре parameter plans × два MIDI-сигнала = восемь outputs на **macOS arm64**. Host CI также выполняется только на `macos-14`; package CI на Ubuntu/macOS не является cross-platform render validation.
- В default core path raw WAV после анализа удаляется, а в dataset остаётся только normalized float32 NPZ и scalar `in_lufs`.
- `quality._mono()` усредняет каналы; `is_silent()` и `clip_fraction()` работают на этом downmix. Fixture с идентичными L/R не проверяет stereo edge cases.
- Поэтому совпадение manifest/output hashes доказано только для fixture/pinned stack и не подтверждает third-party effects, cross-machine identity, raw amplitude fidelity или perceptual quality.

#### Screening audit

Прямой recount, без попытки воспроизвести LMM:

- tie-share `> 1/3`: E = 11/30, N = 12/30, V = 15/30;
- 32-kbps one-sided t-test по описанию не проходит у E, F и K; E попадает в обе группы;
- объединение даёт те же пять исключённых subjects и 21 retained subject, что и статья;
- однако статья описывает порядок `compliance → anchor`, а сообщает разбиение `2 protocol + 3 anchor`, которое получается, если overlapping E отнести к anchor до protocol. Без analysis code классификация и exact preprocessing не воспроизводятся однозначно.

В Phase 1 обнаружены 33 повторные subject/sample/bitrate cells; released CSV не содержит session ID, trial order, A/B assignment или timestamp. Phase 2 полностью сбалансирована по 320 уникальным cells.

#### Statistical boundary

- LMM включает bitrate fixed effects и random intercepts for subject/sample.
- Он не моделирует bitrate random slopes или subject/material × bitrate interaction.
- Phase-2 observations новые, но subjects/material выбраны из Phase 1 по extrema BLUP; вывод относится к selected stress set, не к новой population sample.
- TOST margin ±0.25 взят авторами из PEAQ-related context; независимая пригодность этого числа как project equivalence margin не установлена.
- На 2026-10-16 доступных citers/replications/corrections не найдено; из-за свежести работы это **не подтверждение**. `citation_check:partial`.

## Candidate rules

### RULE-ML-20261016-0900-01 — revision 2: plugin-render provenance gate

- **Когда:** любое исследование или A/B опирается на plugin-rendered audio.
- **Что менять:** сохранить immutable raw pre-normalization output и отдельные derived/matched copies; зафиксировать host/plugin binary hashes, source/tag/commit, build/runtime/native dependencies, ordered parameter definitions, per-attempt requested values and readback, reset/state policy, input/MIDI identity, sample rate/block/channel format, all attempts and failures.
- **Что нельзя испортить:** rights boundary, raw amplitude/transients, channel relationships, length/tail, deterministic replay, failure completeness.
- **Как проверить:** core manifest consistency + host-side attempt trace; per-channel and M/S QC; fresh-process replay on pinned stack; independent cross-platform/plugin validation where claimed; perceptual validation remains separate.
- **Когда отменить:** only normalized outputs retained; readback/reset merely advertised; host trace incomplete; mono QC substitutes for channel QC; third-party rights unclear; output mismatch; fixture evidence generalized to another plugin/platform.
- **Confidence:** `high_for_governance`.
- **auto_apply:** false.

### RULE-ML-20261016-1200-01 — configured codec target is not a delivery threshold

- **Когда:** сравнивается lossy delivery/reference codec.
- **Что менять:** фиксировать encoder/library version, mode, VBR/CBR constraint, configured target и actual per-file bitrate; не переносить чужой threshold.
- **Что нельзя испортить:** source identity, loudness, true peak, stereo image, transients, cymbals/distortion/ambience, metadata alignment.
- **Как проверить:** project-owned excerpts; raw and separately loudness-matched blind pair; listener/material-aware analysis; equivalence only with predeclared project-relevant margin.
- **Когда отменить:** encoder/config mismatch; actual bitrate not recorded; selected material unrepresentative; preference driven by level; confidence interval crosses practical margin; protected-quality regression.
- **Confidence:** `high_for_method_low_for_specific_160kbps_transfer`.
- **auto_apply:** false.
