## Outcome

The foundational [DiffusionRIR paper](https://arxiv.org/html/2504.20625v1) was read in full and linked to the follow-up reviewed at 15:00. The two papers are one method family, not independent confirmation. The foundational training evidence is much narrower than the later paper's language suggests: 176 overlapping `64 x 64` patches come from eight simulated RIR images in one nominal `6 x 5.5 x 2.8 m` room. Training selects source positions from a fixed nine-position semicircle; evaluation uses all nine positions, the same room dimensions and the same Pyroomacoustics/image-source family, while changing material/T60 and array geometry. A source-position-disjoint or room-geometry-disjoint split is not documented.

The strongest revised finding concerns scale reconstruction. Each patch is normalized independently to `[-1,1]`; after inpainting, the paper says that every patch is rescaled to its original energy. For a missing target patch, the text does not define how that original energy is available without target information. This is therefore an underspecified deployability boundary and a possible oracle-dependent step, not a reproducible causal pipeline. Hard centre cropping of 25%-overlapped patches, duplicated-column padding for arrays shorter than 64 microphones and random masks also lack seam, padding and mask-topology ablations.

No official DiffusionRIR code, modified guided-diffusion implementation, configuration, checkpoint, split manifest or preprocessing/reassembly script was found through the paper, author project page, repository search and GitHub code search. Search returned only third-party paper indexes. Absence from these searches is not proof that an artifact does not exist, but exact reproduction is currently blocked.

The official [MeshRIR repository](https://github.com/sh01k/MeshRIR) was inspected at revision [`8a299b62`](https://github.com/sh01k/MeshRIR/commit/8a299b6299b17aae9050cf43e192658dbb482471). Its dataset is explicitly CC BY 4.0 and provides measured 48 kHz RIRs with known geometry. It is suitable as a rights-cleared research benchmark, but not as a rock multitrack or musical Reference Card. The 2026 follow-up downsampled a subset to 8 kHz and 256 ms, so its result still does not validate full-band music reverb.
