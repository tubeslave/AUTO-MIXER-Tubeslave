## Knowledge Card

### KC-ML-20261008-1500-01 — measured residual latency before parallel blend

When a drum path leaves and re-enters the DAW, or any parallel route has uncertain latency, residual alignment is a property of the actual route and session. A short loopback transient can establish the signed sample offset. Correct only the measured residual path latency; do not erase intentional microphone/room arrival differences. Evidence is a fully read vendor-educational article plus a reproducible measurement principle, not an independent controlled music-perception study. Confidence: `medium_workflow / low_musical_generalisation`.

## Candidate Rule

### RULE-ML-20261008-1500-01 — measure before correcting parallel-path latency

- sources: `SRC-ML-20261008-1500-01`, `SRC-ML-20261008-1500-02`
- apply when: clean and processed drum paths are blended and one path uses outboard or otherwise has unknown residual latency
- change: record a short calibration transient through the complete processed route; measure signed offset; apply only that residual correction to the processed path
- proposed range: `no transferable sample range`; measured route-specific value only
- number origin: source demonstration used 15 samples at 96 kHz, explicitly rejected as a reusable setting
- instrument/section: multi-mic rock drum bus or fill bus; any section where both paths are active
- protect: intentional room delay, phase relationships within each stem, kick/snare attack identity, cymbal tone, groove, stereo width and headroom
- verify: retain raw renders; inspect loopback offset, mono sum/correlation and comb-filter notches; perform randomized loudness-matched A/B
- cancel: no stable measured residual, correction worsens mono/impact/room image, or apparent win disappears after loudness matching
- confidence: `medium_workflow / low_parameter_transfer`
