### SRC-ML-20261015-1500-01 — LLM2Fx-Tools

- **Источник:** Doh et al., *LLM2Fx-Tools: Tool Calling For Music Post-Production*, ICLR 2026 / arXiv:2512.01559v2.
- **URL:** <https://arxiv.org/abs/2512.01559>
- **Дата публикации версии:** 2026-01-28; обнаружено 2026-10-15.
- **Глубина:** `full_text` — метод, датасет, объективные результаты, MUSHRA-like listening, ограничения и приложения с метриками/диапазонами параметров.
- **Метод:** мультимодальный Qwen3-4B с Fx-Encoder++, адаптером и LoRA генерирует упорядоченный набор tool calls. LP-Fx содержит 99,900 train и 900 test диалогов, 2019/100 треков, 80/33 инструментов и девять жанров; задача восстанавливает синтетически известную FX-цепь для одиночного инструмента.
- **Результат в пределах работы:** 80% точности выбора модуля, Spearman 0.56 для порядка и нормализованный parameter MAE 0.23. В 8-вопросном MUSHRA-like тесте с 16 участниками LLM2Fx-Tools получил среднее 62.8, выше перечисленных baseline; hidden reference — 81.5.
- **Ограниченный вывод:** структурированные tool calls полезны как проверяемый shadow-план, но не разрешают автоматическое применение. По статье нельзя переносить параметры на full-mix rock, считать CoT доказательством причинности или считать точное восстановление цепи единственно верной целью.
- **Ключевые ограничения:** single-instrument; synthetic known chains; нет unseen-FX test; one-to-many неоднозначность; один экземпляр каждого эффекта в цепи, поэтому нет обычной serial compression/EQ; маленький listening set; тексты/CoT сгенерированы Gemini и оценены LLM-as-judge; статистическая поправка для repeated measures/multiple comparisons в прочитанном описании не установлена.
- **Числовые диапазоны Appendix G:** сохранены только как границы синтетического sampling space, **не** как рекомендуемые rock presets.
