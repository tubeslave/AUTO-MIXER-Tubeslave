## Outcome

Aura remains a research-only mono-to-stereo candidate, but its reproducibility status is now more precise. The complete arXiv HTML method, equations, results and appendix were re-read; the official demo repository, the public Stable Audio 3 dependency, both official model cards and the MUSDB18-HQ rights record were audited. No independent replication, correction or retraction was found; this absence is not confirmation.

The official Aura demo is real and pinned, not merely an unreachable webpage. It exposes 10 five-condition upmix examples, eight six-condition examples including Parametric Stereo, and seven joint low-pass/restoration examples as FLAC players. The page says the main upmix examples are loudness-matched, but supplies no algorithm, target, offsets or hashes. The repository has no licence file, listener-level scores, screening rule, analysis script, frozen stimulus manifest or the referenced build_audio.py. Its eight-condition set plausibly corresponds to the formal eight-excerpt listening test because the six labels match, but the repository does not state that linkage. The audio was not downloaded or played and is not a rights-cleared project asset.

The Stable Audio 3 dependency is better exposed than recorded at 15:00: official code is MIT-licensed, a uv.lock exists, and a pinned public repository documents the 44.1 kHz stereo SAME autoencoder. However, Aura does not identify exact model IDs, weight revisions, code revision, STFT/ERB configuration, reward weights or optimizer constants. The Small and Medium model files are gated behind account/login, contact-information sharing, Community License acceptance and Gemma terms. No account was created, no terms were accepted and no weights were downloaded.

MUSDB18-HQ is officially marked educational-only; constituent tracks also have source-specific rights. Its demonstration excerpts cannot be promoted to a reusable project reference or commercial raw-audio set. The project experiment remains blocked.

The A/B design is corrected: removing the reward phase entirely would change compute and state trajectory as well as reward. The valid one-factor comparison must execute an identical second phase on both sides and vary only a frozen reward multiplier, g_reward=0 versus g_reward=1. Kappa is a target-coherence steering parameter, not an on/off switch; kappa=1 only preserves the reference mean coherence.

No video was promoted in this deep-review run. No new multitrack/reference was added. No audio, model, code, plug-in, Job, GPU or external Space was run. No DSP, runtime rule, repository implementation or audio asset was changed.
