### `SRC-ML-20261004-1500-01` — full text read

**Count-Density Networks for Modal Plate Parameter Estimation** — Rodrigo Diaz, Pablo Tablas De Paula, David Marttila, Ilias Ibnyahya and Chin-Yun Yu, DAFx-26, CC BY 4.0.  
URL: https://www.dafx.de/paper-archive/2026/papers/DAFx26_challenge_87.pdf  
Stable ID: `dafx:2026:DAFx26_challenge_87`

Reading depth: all three pages, preprocessing, architectures, training set, loss, local comparison table, compute statements, limitations and references.

Bounded findings:

- Both methods estimate count plus frequency/decay/gain triples on a `1/20`-octave grid over `20 Hz–10 kHz`. B1 is a roughly `3.1 M` parameter U-Net with time-domain and absolute-scale conditioning; B2 is a roughly `99.6 M` real-parameter-equivalent complex CNN/Transformer.
- Training uses `327,680` five-second synthetic IRs generated from the same reference simulator/default ranges as the benchmark. The authors' `100`-IR comparison set is separately generated but still in-distribution, not a real-plate or simulator-mismatch test.
- On that local set, B1/B2 report total relative error `0.3180/0.3301`; gain remains the dominant component (`0.8525/0.9207`). Hardware timings are not cross-comparable: neural inference is on an A100 GPU, while classical estimators are on 24 EPYC CPU cores. Training took about `24/27 h` on an A100; no training or paid compute was run here.
- Scientific input requires the stored absolute scale `gx`; peak-normalised WAV alone cannot restore modal gains. This agrees with the existing challenge amplitude-contract card.
- The public repository named by the paper currently contains only a “coming soon” README, has no declared repository licence and exposes no implementation. The paper's CC BY 4.0 notice does not license absent code or checkpoints.

Evidence confidence: high for the paper's stated in-distribution protocol and table; low for measured-plate, noisy/OOD, perceptual or production transfer.
