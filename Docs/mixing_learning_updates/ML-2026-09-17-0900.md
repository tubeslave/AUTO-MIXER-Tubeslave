## Literature — genuinely read

### `S-ML-20260917-0900-01` — PolyADAA

The complete eight-page paper was read: [Gabrielli & Squartini, *PolyADAA: Improving Aliasing Reduction in Memoryless Nonlinearities Using Lagrange Interpolation and Polynomial Approximation*](https://dafx.de/paper-archive/2026/papers/DAFx26_paper_47.pdf), DAFx-26, CC BY 4.0.

Supported conclusions:

- PolyADAA replaces ADAA's linear input interpolation with quadratic/cubic Lagrange interpolation and approximates the composed nonlinearity with Chebyshev polynomials so the finite-support antialiasing integral remains tractable.
- Tests used 48 kHz sine tones driven heavily into `tanh` and hard clipping. Across MIDI notes 69–108, several PolyADAA configurations improved objective SNR over ADAA; the useful configuration depended on kernel, interpolation order and frequency range.
- Cost is materially configuration-dependent. In the authors' C++ benchmark on an Intel i7-1360P, processing 48,000 samples took 11.7–71.1 ms for tested direct PolyADAA variants versus 0.9 ms for rectangular ADAA and 6.9 ms for triangular ADAA. LUT approximation reduced some PolyADAA cases substantially, while adding a numerical noise floor.
- The paper provides a public MATLAB companion repository, but its README says “free to use” without an explicit standard licence file. The repository was inspected but not executed or integrated.

Limits:

- No listening test, rock programme material, mastering chain, oversampled-clipper comparison or intersample/true-peak evaluation is reported.
- Reported SNR and spectra do not establish preferred distortion colour, better transients or better masters.
- `N`, `K`, kernel and LUT sizes are experimental parameters, not genre presets.
- Reproducibility is `partial`: paper and README were read, code was not run, and repository licensing remains ambiguous.
