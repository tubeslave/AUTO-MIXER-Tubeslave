## Deep-review outcome

The central correction is that three materially different mechanisms must not be called the same thing:

1. Open-Amp's released universal model uses a closed-set learned lookup ID for each training device/condition.
2. Open-Amp's paper enrols an unseen pedal by freezing the network and optimising a new embedding from paired clean→processed target audio; this is supervised adaptation, not zero-shot inference.
3. The comparator *Towards Zero-Shot Amplifier Modeling* derives a condition directly from an unaligned wet reference without retraining; this is closer to zero-shot reference conditioning, but its encoder/data are proprietary and its evidence covers only two unseen amps with objective loss and an author case study.

These routes require different baselines, permissions and deployment claims. A stored embedding, an audio-derived embedding and an optimised embedding are not interchangeable.

## Sources actually read

### SRC-ML-20260921-0900-01 — Open-Amp, updated

[Full paper](https://arxiv.org/html/2411.14972), arXiv `2411.14972`, DOI `10.48550/arXiv.2411.14972`.

- The foundation model is conditioned by a lookup table with one learned embedding for each of 394 synthetic device/condition states.
- The unseen-device experiment uses three EGFX analogue pedals, a 90/5/5 split and paired clean/processed audio. All network parameters except the embedding are frozen; the initial embedding is selected as the existing Open-Amp embedding with the lowest loss on the unseen target data.
- Therefore enrolment is target-aware supervised adaptation. It cannot be used where only an arbitrary commercial reference mix is available, and the lowest-loss initialisation is an oracle unless target processed audio is available to the selector.
- The five selected rows in Table III imply Emb-256 ESR penalties of approximately `0.4 / 5.4 / 4.8 / 3.4 / 4.7 dB` relative to one-to-one baselines. The rounded table therefore slightly exceeds the prose claim of “at most 5 dB”.
- No controlled listening test, seed robustness, confidence intervals, raw peak/phase/aliasing tests or real-time benchmark is reported.

### AUD-ML-20260921-0900-01 — OpenAmp repository, updated

[Repository](https://github.com/Alec-Wright/OpenAmp), revision `b57993408a61d94bf9425ca0acf7af4b3c27f3eb`; static audit only.

- `run_uni_amp.py` loads only `train_index.csv` and accepts a closed-set integer `device_id`; it contains no unseen-device enrolment path.
- The shipped index contains 394 training rows from 150 unique capture files and 26 test rows from 10 capture files. The inference example cannot address the test rows because its embedding table is built from the 394 training rows.
- `train_universal_amp.py` creates `test_devs` but constructs both online training and validation datasets with `train_devs`. Validation uses a different input guitar, which checks some content transfer, but not unseen-device transfer.
- The public checkpoints/configurations use embedding dimensions 4 and 8 at epoch 3. The paper reports dimensions 16, 64 and 256 trained for 8 epochs. The generic training script instead loops for 1000 epochs. These are different artifacts/configurations, so the published tables are not reproduced by the included quick-start path.
- Validation targets are generated and cached on demand when absent. This is operationally useful, but without an immutable data/config manifest it can mix results from different capture/model revisions.

### SRC-ML-20260921-1200-01 — primary comparator

[Towards Zero-Shot Amplifier Modeling: One-to-Many Amplifier Modeling via Tone Embedding Control](https://arxiv.org/html/2407.10646), arXiv `2407.10646`, DOI `10.48550/arXiv.2407.10646`, ISMIR 2024. Reading depth: `full_text_complete`.

- Unlike Open-Amp enrolment, its non-retrieval path produces a 512-dimensional tone condition from an unaligned wet reference and does not retrain the generator at inference.
- It tests only two unseen amplifiers. One-to-many loss remains above one-to-one on all nine seen amps; unseen high-gain complex-STFT loss is much worse than the unseen low-gain case.
- The authors explicitly report high-frequency and sustain failures in the self-recorded case study. The target also included an EQ high-cut that the model was not designed to reproduce.
- The encoder and its large training corpus are proprietary Positive Grid assets. There is no controlled listening test or public reproduction path. This is useful conceptual evidence, not an independently deployable open baseline.

### SRC-ML-20260921-0900-02 — GOAT, updated

[Full paper](https://arxiv.org/html/2509.22655v1), arXiv `2509.22655`, DOI `10.48550/arXiv.2509.22655`.

- From the paper's Table IV, AMP versus DI changes note F1 by approximately `+0.0222` on GOAT-DI, `+0.0862` on GOAT-AMP and `−0.0174` on GuitarSet. Thus “without sacrificing quality” is too broad: the acoustic-domain score fell.
- AMP-XL versus AMP changes F1 by `−0.0246` on GOAT-DI, `+0.0060` on GOAT-AMP and `−0.0080` on GuitarSet. More timbral variants helped the matching amplifier domain slightly while harming the other two domains.
- No repeated seeds, confidence intervals or significance test are reported, so these differences are directional results for this split, not stable universal gains.
- The Whisper/DadaGP experiment selects best epochs and produces superficially high token accuracy while notes do not correlate with ground truth; the paper correctly identifies wait-token dominance. Such metrics must not be used as musical approval.

### AUD-ML-20260921-0900-02 — GOAT repository, updated

[Repository](https://github.com/JackJamesLoth/GOAT-Dataset), revision `55c6e6668ef4546e4635c5e7eaad3062cf7f036b`; static audit only.

- The paper says the rendering process was repeated five times; the public notebook contains one rendering loop and no explicit five-pass loop. Re-running manually would produce different uncontrolled choices.
- The notebook says the alignment CSV will be made available, but the pinned repository contains no such CSV. Exact item filtering at `f_measure_fine ≥ 0.75` is therefore not reproducible from the public tree.
- Random preset, mic, position, distance, phase, room enablement and send are not seeded or saved into an output manifest. The output filename hashes only source path plus loop index, not the processing state.
- The split is selected by literal song-name substrings while the paper says song/artist names were removed. This public helper is not a complete anonymous-dataset construction recipe.
- Two example bundles are present, but no root licence or per-file provenance/rights map was found; their audio was not analysed or promoted to Reference Cards.

## Conclusions revised

- “Open-Amp supports zero-shot unseen devices” → its reported unseen-device route is supervised embedding enrolment with paired target audio and oracle lowest-loss initialisation.
- “The public Open-Amp demo validates unseen devices” → it validates training devices on another input guitar; the declared test-device table is not consumed.
- “The released checkpoint reproduces the paper” → checkpoint embedding sizes/epoch and the quick-start training schedule differ from the reported experiment.
- “GOAT augmentation improves generalisation without cost” → benefit is strongly domain-dependent, and extra augmentation slightly improves only the matching amp domain while degrading DI and acoustic results.
- “The GOAT notebook reproduces 29.5 hours” → the public helper lacks the five-pass driver, alignment CSV, fixed seed and processing manifest.
