## Source Card added

### SRC-ML-20261018-0900-01 — PADP metric-robustness probe

- Stable ID: `arxiv:2610.01405v1`
- Canonical URL: https://arxiv.org/abs/2610.01405
- Full text: https://arxiv.org/html/2610.01405v1
- Authors: Guanxin Jiang, Andreas Brendel, Pablo M. Delgado and Jürgen Herre
- Publication state: `preprint`; submitted 2026-10-01; licence shown by arXiv: `CC BY-NC-ND 4.0`
- Reading depth: `full_text_complete_5_pages`
- Citation check: `partial`
- Artifact status: `not_found`; targeted exact-title/GitHub search found no official code, stimuli or results manifest.
- Method: four intended perceptually irrelevant perturbation families—bandwise all-pass phase changes (`APX`), frequency-selective delay (`DEL`), scaled codec distortion (`SCD`) and decorrelator/diffusion (`DIF`)—implemented in a 64-band QMF framework grouped to 23 perceptual bands.
- Listening evidence: two MUSHRA tests over 12 ODAQ clean items, mono only (left channel); hidden reference and 3.5 kHz low-pass anchor; high-quality headphones in a quiet environment. Post-screening retained only 9 listeners for SCD and 8 for APX/DEL/DIF.
- Reported operating points: APX uses offset 1, stride 4 and angular step `pi/2`; only 12 of 4096 possible combinations were sampled. SCD scales MP3 80 kbps residual with `lambda` in `{0.2,0.6,0.9,1.2}`. DIF tests orders 1, 3 and 5. These are paper provenance, not automixer settings.
- Author criterion: mean difference grade below 10 relative to the hidden reference is treated as transparent. This is an operational threshold chosen for the paper, not universal inaudibility.
- Reported result: DeePAQ has the highest absolute SRCC (`0.74`) and ViSQOL v3 the lowest (`0.38`) over this constructed PADP set; the remaining tested metrics/embeddings lie roughly between `0.60` and `0.70`. This is not a universal metric ranking.
- Bounded conclusion: listener-transparent waveform changes can substantially move some objective metrics and embeddings. A single objective metric must not be the sole acceptance gate for mix/DSP variants.
- Limits: very small retained listener samples; 12 source items; mono-only evaluation; DIF stereo output reduced to the left channel; no rock-mix or stereo validation; post-screened results; no reported uncertainty intervals or listener/material mixed-effects model; no released implementation found.
