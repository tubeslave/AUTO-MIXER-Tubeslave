## Deep-review result

The full public inference path of SpanSynth-Edit was audited at repository revision [`c89cd924`](https://github.com/mimbres/spansynth-edit/commit/c89cd92420e3a44d450fb624f9df589560ec4a38) and compared with the full text of [arXiv:2609.25546v1](https://arxiv.org/html/2609.25546). The linked MambaVoice repository was checked once and still returned HTTP 404.

The main revision is configuration parity. Tables 1–2 in the paper use contextual audio **and contextual MIDI**, 32 Euler steps and CFG 2. The released CLI and Diffusers pipeline default to contextual audio, **no contextual MIDI**, 16 steps and CFG 2. Public defaults are therefore a different inference condition, not a direct reproduction of the reported tables. The paper's own 56-interval ablation shows a trade-off rather than a monotonic step benefit: from 8 to 64 steps FAD improves, while MuQ-Eval and onset F1 decline; the intervals are clustered over only seven recordings and are not dataset-specific estimates.

The audit also narrows the preservation claim. The implementation keeps samples outside the applied interval exactly, but first averages every input to mono and resamples it to 48 kHz. The protected reference is therefore the resampled mono crop, not the original stereo file. Inside the interval, all audio is decoded and hard-spliced with no crossfade. Peak normalization is source-only and thus avoids target leakage, but the inverse gain can produce output above full scale; the CLI only warns and does not limit or reject it.

### `SRC-ML-20260923-0900-01` — SpanSynth-Edit (`update`)

- Reading depth remains `full_text_complete`; methods, experiments, ablations and appendices were rechecked.
- Paper evaluation contract: 48 kHz mono; contextual audio and MIDI; 32 Euler steps; CFG 2. Public runtime defaults differ on two factors: 16 steps and contextual MIDI disabled.

### `AUD-ML-20260923-0900-01` — SpanSynth-Edit public artifact (`update`)

- Audited files: MIDI parser/encoder, Fine40 vocabulary, audio I/O, checkpoint resolution, CLI, Diffusers pipeline, ordinary/FlowEdit sampling, Gradio region selection and relevant tests. Static inspection only.
- Audio contract: arbitrary input channels are averaged to mono, resampled to 48 kHz, cropped and optionally source-peak-normalized when the history-plus-payload peak exceeds 0.95. The generated region is divided by that source gain during assembly. There is no target-aware/oracle normalization, but no post-assembly limiter or true-peak gate.
- Boundary contract: requested bounds are rounded outward to the 25 Hz grid. Automatic region selection covers changed notes and also rounds outward. Assembly is a direct replacement on the mono timeline without a fade.
- MIDI contract: target MIDI is used inside the generated mask. Source MIDI outside the mask is included only when `context_midi=true`; this is false by default despite being enabled for the paper's main tables.
- Fine40 collapses many General MIDI programs into one model category. For example, programs 29–31 all map to `Distorted Electric Guitar`. A program change inside one category can trigger UI regeneration while presenting no instrument-category change to the model.
- Capacity is explicit and fail-closed: more than 128 active event rows in a frame raises `MidiOverflowError`; statistics are available. This is a positive safety property, but dense arrangements need preflight logging.
- FlowEdit starts from clean codes and subtracts source from target vector fields. With identical target/source MIDI and identical model inputs, the delta is structurally zero; the included equality test uses a constant toy model. This is useful plumbing, but it is not a real-checkpoint perceptual null test. The meaningful unchanged-content null for the ordinary generator remains codec-only versus ordinary regeneration with identical MIDI.
- Reproducibility remains incomplete: public runs draw fresh PyTorch randomness; no seed is exposed or written to `run.json`; downloaded assets default to mutable Hugging Face revision `main`; file hashes are not recorded. The documented Diffusers route uses `trust_remote_code=True`, so an immutable reviewed revision is required before execution.
- Tests verify MIDI parsing, capacity failure, mocked sampler algebra, serialization and exact outside-interval samples. They do not run the released checkpoint/codec or test clicks, stereo image, gain continuity, transients, true peak, seed robustness or musical preference.
