## What was actually read

### Source Card `SRC-ML-20261014-1500-01`

**MPASCNet: Magnitude-Phase-Aware Adaptive Spectral Compression for Compressed Music Restoration**

- DOI: none found; stable ID `arXiv:2610.16416v1`.
- URLs: [abstract](https://arxiv.org/abs/2610.16416), [full HTML](https://arxiv.org/html/2610.16416v1), [code](https://github.com/xinghour/MPASCNet), [checkpoint card](https://huggingface.co/Xinghour/MPASCNet).
- Publication status: ICASSP 2027 submission/preprint, not peer reviewed.
- Reading depth: full HTML paper; methods, tables, ablation and limitations; selected public implementation files and metadata.
- Citation check: `partial` — the preprint is two days old and no independent replication was found; absence of a found correction is not confirmation.

**Verified method.** The model uses 80 learnable spectral tokens, six spectro-temporal blocks and separate magnitude/phase branches; 6.49 M parameters. Training uses MUSDB18-HQ plus MoisesDB, random active-stem mixtures, three-second excerpts and MP3 bitrates 24/32/48/64/96/128 kbps. Evaluation uses MedleyDB after removing 46 tracks overlapping MUSDB18-HQ, leaving 150 tracks; each of Multi-Stem, Single-Stem and Vocal has 500 deterministic three-second excerpts. Audio is 44.1 kHz; STFT window 882 samples, hop 441. The composite loss weights are magnitude 1.2, phase 0.3, complex 0.1, STFT 0.1 and waveform 0.2.

**Verified results.** On the reported aggregate set, MPASCNet scores 17.65 dB SDR, 17.27 dB SI-SNR and 3.67 ViSQOL versus Apollo 16.61/15.77/3.60 and AEROMamba 16.26/15.73/3.49. These are author-reported objective results, not an independently reproduced listening result. No human listening test is reported.

**Ablation warning.** Removing adaptive spectral compression worsens SDR/SI-SNR/ViSQOL (17.24/17.01/3.61) but improves phase distance and LSD (13.35 degrees and 0.87 versus 13.80 and 0.92). The metrics therefore disagree; no single metric establishes perceptual dominance.

**Transfer limits.** The task is synthetic MP3 restoration, not mixing, mastering or source reconstruction. The evaluation uses short synthetic degradations, no natural commercial-delivery chain and no human listening. The code flattens stereo into independent channel examples and restores each channel independently; it does not explicitly model inter-channel coherence. Any use on a stereo master must therefore gate side image, correlation and channel balance.

## Bounded rule candidate

### `RULE-ML-20261014-1500-01` — codec restoration, shadow only

- **Source:** `SRC-ML-20261014-1500-01`, artifact audits above.
- **When:** a project-owned or rights-cleared stereo file is known to be low-bitrate MP3 damaged and a lossless source is unavailable; diagnostic/research context only.
- **Change:** compare restoration off/on locally. Do not use it as a loudness, mastering or source-separation stage.
- **Range/origin:** one fixed, verified checkpoint and one fixed bitrate condition at a time; paper bitrates 24–128 kbps are dataset conditions, not recommended mix settings.
- **Protect:** transient shape, cymbal texture, consonants, bass definition, stereo image/correlation, side-channel balance, noise texture, loudness, true peak and artistic intent.
- **Verify:** raw comparison to a known lossless original where available; separate BS.1770-matched, true-peak-safe blind listening by Dmitry; log SDR/SI-SNR/LSD/phase-distance only as diagnostics.
- **Cancel:** new pre-echo/warble, widened/narrowed image, repeatable transient or timbre regression, gain-only preference, checkpoint/hash/licence ambiguity or absent known reference.
- **Confidence:** medium for the narrow synthetic-MP3 hypothesis; low for real masters.
- **auto_apply:** `false`.
