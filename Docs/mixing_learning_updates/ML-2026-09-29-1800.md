### SRC-ML-20260929-1800-01 — Simulation-Based Plate-Reverb Parameter Estimation from a Single Impulse Response

- Stable ID: `arxiv:2608.00656`; proceedings version: `DAFx26_challenge_81`
- Authors: Minhui Lu; Joshua D. Reiss
- URL: https://www.dafx.de/paper-archive/2026/papers/DAFx26_challenge_81.pdf
- Publication/discovery date: 2026-08 / 2026-09-29
- Licence: CC BY 4.0
- Reading depth: `full_text_complete_4_pages`
- Evidence family: same DAFx synthetic plate benchmark; independent estimator, not independent real-world validation.

Verified method and result:

1. A 372-feature vector covers amplitude, spectrum and decay; separate ExtraTrees and histogram-gradient-boosting regressors are trained per parameter and averaged.
2. Training uses 1,000 synthetic examples. Validation 1 has 24 examples and influenced development; Validation 2 has 12 examples after the estimator was fixed.
3. Ensemble NMSE is `0.011886` on Validation 1 and `0.012935` on Validation 2. The single histogram-gradient-boosting model is slightly better on Validation 2 (`0.012063`), so averaging is not uniformly beneficial.
4. The paper's PSO comparison is one fixed-seed run on 12 examples; it is useful but weak baseline evidence.
5. Released-target processing takes 15.03 s for 16 IRs on an M1 Pro CPU (about 0.94 s/IR). Target diagnostics have no parameter ground truth; one IR is a clear response-error outlier.
6. The paper explicitly separates parameter error from response similarity and provides no uncertainty estimate.
7. Official result: rank 9; mean/median parameter NMSE `0.010` / `0.006`; mean/median SMSE `0.558` / `0.550`.

Limits: small validation sets; exact simulator only; no measured/noisy/model-mismatched plates, listening test or music mix; no uncertainty; no method-specific source code, saved estimator, feature implementation or pinned environment found in the inspected paper/project searches.

### SRC-ML-20260929-1800-02 — Accurate Plate Reverb Parameter Estimation Using Two-Stage Evolutionary Search

- Stable ID: `arxiv:2608.28818`; proceedings version: `DAFx26_challenge_83`
- Authors: Byunghoo Park; Jayeon Yi; Takyoung Kim; Minje Kim
- URL: https://www.dafx.de/paper-archive/2026/papers/DAFx26_challenge_83.pdf
- Publication/discovery date: 2026-08 / 2026-09-29
- Licence: CC BY 4.0
- Reading depth: `full_text_complete_4_pages`
- Evidence family: same DAFx synthetic plate benchmark; independent method, not independent real-world validation.

Verified method and result:

1. Only the first 0.25 s of each 44.1 kHz IR is used. Stage 1 applies CMA-ES to peak-normalised candidate/target IRs and an uncompressed L1 STFT-magnitude loss (4096-point Hann, hop 1024), estimating five shape/geometric parameters.
2. Stage 2 fixes those five parameters and estimates `mu` from the unnormalised IR with a 50-iteration ternary search. This is an explicit nuisance-removal/scale-recovery split, not blanket normalisation.
3. Under the exact simulator, uncompressed L1 STFT reaches a geometric-mean NMSE near `4.9e-14` with 100% convergence on 50 tests. Log-compressed variants sharply reduce exact-recovery convergence; this is task-specific evidence, not a general perceptual-loss result.
4. Stage 2 improves 49/50 validation cases; median NMSE changes from `1.91e-3` to `1.34e-14`. One near-boundary pickup position (`xo=0.999980`) creates severe amplitude sensitivity and corrupts `mu` estimation.
5. Stage-1 median/mean runtime is 32.6/76.9 s and Stage 2 averages 0.62 s in the paper's validation. Official challenge inference averages 114.74 s and 13,368 evaluations.
6. Official result: rank 2; mean/median parameter NMSE `1.933e-11` / `3.103e-14`; mean/median SMSE `6.836e-10` / `3.738e-10`.

Limits: exact known simulator; only 16 secret test IRs; no measured plate, noise, model mismatch, listening or mix context; runtime has a long tail; no method-specific implementation, seed/restart manifest or pinned environment found in the inspected paper/project searches.
