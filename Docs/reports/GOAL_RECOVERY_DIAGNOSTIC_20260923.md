# Продвижение к цели: проверка восстановления спектра

Дата: 2026-09-23. Исходный HEAD: `64111ba52`.

Реальные возможности добавлялись: офлайн-рендер, DSP-исправления,
Instrument Space и интерфейс предложений. Однако число коммитов и зелёных
контрактных тестов не доказывает качество автономного микширования.
`recovery_trial.run_trial` до этой проверки вызывался только тестами самого
стенда: oracle, бездействие, половинный и заведомо вредный ремонт. Его связь
с реальным анализатором отсутствовала. M110-HW01..HW05 остаются незавершёнными
в текущем `STATE.json`; полная автономия не доказана.

Предыдущий пересказ старого writer lease не считается прогрессом или
подтверждённым ожиданием: сейчас lease отсутствовал, живой процесс не был
установлен. Этот цикл получил новое численное evidence и исправил его причину.

## Эксперимент

Три независимые реализации розовоподобного шума: seeds 7, 23, 91, 4 секунды,
48 кГц, peak 0.3. Шесть дефектов из `recovery_trial.DEFAULT_CORPUS`.
Корректор получает только повреждённый сигнал. Использованы реальный
`SpectralCeilingEQAnalyzer`, перевод предложений `_spectral_actions_for_proposal`
и `mix_agent.actions.base.apply_parametric_eq`. Дефект и чистый оригинал
доступны только оценщику. Измерена одна спектральная стадия, не полный микшер.

| Метрика | До | После |
| --- | --- | --- |
| Средняя доля восстановления, seed 7 | 0.0319 | 0.0635 |
| Средняя доля восстановления, seed 23 | 0.0317 | 0.0636 |
| Средняя доля восстановления, seed 91 | 0.0316 | 0.0634 |
| Восстановление scoop 1 кГц | -0.1900..-0.1912 | 0.0000 |
| Изменение чистого контроля | 0 дБ | 0 дБ |

Ноль для scoop означает сохранение исходного повреждённого сигнала:
ненужные срезы устранены, сам провал не восстановлен. Полезные срезы mud,
harshness и boxiness сохранены. Boom и dullness остаются неисправленными.
Порог 0.9 не достигнут. Три шума не заменяют три мультитрека и слепое
прослушивание; эти числа не являются процентом готовности проекта.

## Изменение

Для mix_bus опорный уровень теперь оценивается медианой спектра после
вычитания заданного наклона в диапазоне 80 Гц..14 кГц. Локальный провал
около 1 кГц больше не опускает весь потолок. Привязки отдельных инструментов,
ограничения EQ, confidence и полномочия пульта сохранены.

Воспроизведение: `PYTHONPATH=backend python -m pytest
tests/test_recovery_trial.py tests/test_spectral_ceiling_eq.py -q`.
До исправления три новых recovery-теста упали с точной ошибкой около -0.19.
После исправления предварительный прогон: 22 passed. Добавлена проверка
разных заданных наклонов; окончательные проверки выполняются после записи
этого отчёта. Полный suite и независимое ревью здесь не объявлены успешными.

## Следующий результат

Подключить полный действующий офлайн-пайплайн к восстановительному стенду
на трёх различных мультитреках. По каждому дефекту сохранять before/after,
дистанцию до оригинала и неизменённый контроль. Затем исправлять наибольшую
измеренную потерю, проверяя сходимость после действия. Не повышать оценку
проекта за этот локальный фикс; аппаратные проверки остаются отдельными.

Аппаратных соединений, захвата аудио и записей в пульт в этом цикле нет.
