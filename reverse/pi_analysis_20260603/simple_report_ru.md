# Простой отчет по Pi

## Что нашли

Найден плагин Sound Radix `Pi`, версия `1.1.3`.

Он установлен здесь:

- `/Library/Audio/Plug-Ins/VST3/Pi.vst3`
- `/Library/Audio/Plug-Ins/VST/Pi.vst`
- `/Library/Audio/Plug-Ins/Components/Pi.component`

Бинарник открыт в Binary Ninja через VST3:

```bash
open -a "/Applications/Binary Ninja.app" /Library/Audio/Plug-Ins/VST3/Pi.vst3/Contents/MacOS/Pi
```

## Что нового выявлено

Pi не похож на smartEQ4. У него не видно большой ML/ONNX-системы и
инструментальных `.nn` моделей. Он больше похож на фазовый групповой
координатор.

Найдены такие важные элементы:

- `Group`
- `Group Enable Mode`
- `Group Gain`
- `Gain`
- `Weight`
- `Global Low Freq Focus`
- `Global Enabled`
- `Master Bypass`
- `lookahead_buffer_ms`
- `report_latency`
- `logic_latency`
- `GROUP_FULL`
- `GROUP_INTERNAL_ONLY`
- `GROUP_PHASE_LOCK`
- `GROUP_OFF`
- `Phase-Lock`

Простыми словами: плагин группирует каналы, назначает им вес, умеет работать с
низкими частотами отдельно и имеет режим фазовой блокировки.

## Какие функции понятны по анализу

- Группа каналов: несколько дорожек можно рассматривать вместе.
- Вес канала: один канал может быть важнее другого.
- Фазовая блокировка: можно сохранить один канал как опору, а остальные
  подстраивать относительно него.
- Low Freq Focus: особое внимание низу, где фаза сильнее всего портит звук.
- Lookahead/latency: плагин может буферизовать сигнал и сообщать задержку хосту.
- Графики: есть признаки group graph и frequency graph.

## Что применить в AutoMixer

Главная идея: перед EQ надо проверять фазу.

Если два микрофона конфликтуют по фазе, звук может стать тонким, пустым или без
низа. В такой ситуации обычный EQ может ошибиться: система начнет поднимать бас
или тело, хотя настоящая проблема не в частотах, а в фазовом сложении.

Для AutoMixer это значит:

1. Сначала проверить группу каналов: барабаны, бас, гитары, вокальные дубли.
2. Найти канал-опору.
3. Проверить задержку, полярность, coherence и group delay.
4. Если проблема фазовая, предложить delay/polarity candidate.
5. Только потом делать EQ.
6. В live режиме не применять автоматически, а показывать оператору proposal.

Коротко: Pi учит нас, что хороший AutoEQ должен быть не только спектральным, но
и фазово-групповым. То есть AutoMixer должен спрашивать: "Это правда надо
эквализировать, или сначала надо выровнять фазу между каналами?"
