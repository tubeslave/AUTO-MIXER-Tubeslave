# KVMS / КВМС v0.2 — офлайн-прототип для Automixer

**Исследовательский статус.** Не подключён к mixer runtime. Не предсказывает слуховое предпочтение. Не отправляет OSC.

## Запуск

Требуются Python 3.10+, `numpy`, для тестов `pytest`.

```bash
python -m pytest -q test_kvms_shadow.py
python demo.py
```

`synthetic_probe_results.json` содержит результат на двух синтетических синусоидах и явно помечен `human_test=not_run`, `live_test=not_run`.

## Состав

- `KVMS_Theory_and_Implementation_v0.2.md` — теория, исследования, архитектура, план проверки на «Пене».
- `KVMS_ADR_v0.2.md` — архитектурное решение и rollback.
- `KVMS_Study_Manifest_v0.2.json` — машинно читаемый реестр.
- `kvms_shadow.py` — автономный инженерный индикатор спектрального перекрытия.
- `test_kvms_shadow.py` — тесты отказов и детерминированности.
- `demo.py` / `synthetic_probe_results.json` — воспроизводимая синтетическая проверка.

## Границы

Для спектрального расчёта нужны независимые, выровненные, сухие моноисточники. Для live каналов, где bleed может влиять на источник, система отказывается от интерпретации без независимой атрибуции. Любое предложение о gain является `candidate_shadow`, с `auto_apply=false`. Положительная разница proxy не означает улучшение восприятия.
