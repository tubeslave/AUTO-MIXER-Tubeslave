# Живой саундчек с DSP v3 — 2026-07-05

Полный прогон режима саундчека (`AutoSoundcheckEngine`, auto_apply) на
реальном WING Rack «ATMOSPHERA-WNG» (FW 3.0.5) по команде оператора.
Состав: KICK, SNARE T/B, TOM, F TOM, OH L/R, BASS, GUITAR L/R,
PLAYBACK L/R, ACCORDION, VOCAL (ch 1–13, 16; ch 14/15 = USB-возвраты,
исключены).

## Что применил движок сам (профиль show_assist_auto_v1)

- **Gain v3 (тримы, только вниз)**: KICK −11.0 дБ (TP −5.0 → цель −16),
  GUITAR L/R −6.3/−5.4, PLAYBACK −1.6/−1.5. Boost-запросы (+5.4 SNARE,
  +9.9 TOM и др.) честно пропущены: live-политика не доверяет тихому
  замеру при bleed.
- **Balance v3 (фейдеры)**:微шаги −1.0…−1.5 дБ первого цикла к целям
  решателя (KICK → −12, SNARE T → −8.5 и т.д.; вокал-референсная
  плоскость на Ayaic-якоре). Движок остановлен после одного цикла —
  дальнейшие шаги идут в мониторном режиме.
- **Comp v3**: все 14 каналов — bypass. Гейт сработал (sigma/crest),
  но верификация симуляцией не прошла (пампинг/bleed-lift после мягкой
  деградации) → proposal-only, на пульт не писалось. Это спроектированное
  поведение.
- **Pan v3**: BYPASS — конфиг PA по умолчанию mono (консервативно).
- **FX-посылы**: отключены для live-safety (авто-FX не пишутся).
- **Феdback-детектор**: событий нет.

## Найденные и исправленные баги движка

1. `_apply_eq`: UnboundLocalError `eq_bands` на v3-пути — цикл лога
   изменений использовал переменную preset-ветки. EQ v3 в движке падал
   на КАЖДОМ канале (глушился broad-except как «EQ failed»).
   Исправлено.
2. `_apply_compressor`: лог bypass печатал причину триггера
   (`sigma_level_above_threshold`) вместо реальной причины
   (верификация не пройдена) — вводил в заблуждение. Исправлено:
   приоритет предупреждения верификации.

## Наблюдения для калибровки

- Comp v3 верификация отвергла все каналы даже после перекалибровки
  PUMPING_LIMIT 0.35→0.6 — на этом материале узкое место, вероятно,
  bleed-lift (makeup 2 дБ поднимает паузы с bleed > 3 дБ). Кандидат
  на следующую калибровку: BLEED_LIFT_LIMIT_DB против реального bleed
  или makeup=0 по умолчанию в live.
- Индекс USB-устройства WING плавает (1→2 между сессиями) — выбирать
  по имени, не по индексу.
