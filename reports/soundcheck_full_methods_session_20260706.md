# Саундчек с полным набором методов на реальном WING — 2026-07-06

Директива оператора: «проводи саундчек с пультом, исправляя баги и ошибки,
до полной работоспособности и адекватного поведения DSP и применения всех
методов коррекции к реальному пульту». Три полных прогона
`AutoSoundcheckEngine` + SETUP FX-рэка; все найденные баги исправлены,
итоговое состояние: **каждый метод либо применяется на пульт с readback,
либо даёт честный обоснованный bypass**. Коммит: `57beb43c0`,
5795 тестов зелёные.

## Что теперь реально применяется (проверено на пульте)

| Метод | Статус на пульте |
|---|---|
| Gain/trim (gain v3) | ✅ абсолютные цели к −16 dBTP, boost запрещён live-политикой |
| Fader (balance v3) | ✅ микрошаги ≤1 дБ к вокал-референсным целям |
| EQ v3 + HPF | ✅ полосы+`eq/on` одной операцией; retune к существующим полосам |
| Компрессор (comp v3) | ✅ KICK −18/2.5:1, SNARE T −21/2.5, SNARE B −15/2.7, OH R −32/2.6, VOCAL −31/2.3 (+makeup 2 дБ) — все верифицированы симуляцией |
| Гейты (drum close-mics) | ✅ пороги по замеру, range/sidechain по правилам |
| Pan v3 (stereo/club) | ✅ 3 якоря в центре (KICK/BASS/VOCAL), барабаны/гитары/playback разведены ±15…±45 |
| Phase (snare T/B) | ✅ 1.08 мс абсолютно, идемпотентно («already at absolute target» на повторе) |
| FX-рэк | ✅ PLATE→шина13, ROOM→14, ST-DL→15 (инсерты, выходы в мейн, параметры от темпа) |

## Инфраструктура промоута (операторское решение)

Один источник истины — `live_action_executor.promoted_action_types` в
automixer.yaml: промоутнуты EQ/HPF/comp/makeup/gate/pan/delay/polarity/
send. Каждая запись идёт через gated executor: pre-read → bounded →
запись → физический readback → rollback-действие; несовпавший readback
автоматически откатывается. Мьюты, мастер/DCA/шинные фейдеры остались
proposal-only (транслятора нет — промоут в конфиге их не оживит,
закреплено тестом).

В фазах саундчек-деривации действуют АБСОЛЮТНЫЕ клампы (EQ ±9 дБ,
delay ≤10 мс) вместо пошаговых live-лимитов — по доктрине идемпотентных
целей CLAUDE.md.

## Баги, найденные живыми прогонами и исправленные

1. `set_compressor` писал порог только в `thr26` — при модели COMP
   запись молча терялась (то самое правило CLAUDE.md). Теперь оба адреса.
2. Верификация comp v3 умела только удлинять релиз: барабаны (crest
   ~39 дБ!) упирались в GR 7–10 дБ и вечный провал. Лестница деградации:
   релиз ×2 → порог +3 дБ шагами → честный bypass при GR<1.5 дБ.
   Барабаны сходятся к GR 2–4 дБ.
3. Роли camelCase (`leadVocal`) не находили профили CLASS_PROFILE
   (`lead_vocal`) — вокал считался generic. Добавлены алиасы.
4. Фазовый белый список сравнивал строки ролей: `oh_l`/`oh_r` — разные
   строки одной стереопары → оверхеды получили выравнивающую задержку
   (разрушение стереоинформации). Канонизация в семейства + консервативный
   отказ для unknown-ролей. Ошибочная задержка на пульте откатана.
5. **Интеграторный храповик фазовой задержки**: цель считалась
   `current + measured`, а pre-trim USB tap не отражает применённую
   задержку → тот же замер 0.58 мс прибавлялся каждый прогон
   (1.10→1.68). Теперь цель АБСОЛЮТНАЯ (задержка опорного канала +
   замер) с деад-бендом 0.15 мс — на повторе «idempotent skip».
6. Коридорный страж молча блокировал ВСЕ верифицированные
   comp-предложения и посылы (невидимо при выключенном autofoh-логе).
   Блокировки теперь логируются; comp/посылы выведены из-под стража в
   деривационных фазах (их громкостный эффект верифицирует собственный
   A/B-контур comp v3).
7. Legacy-адаптация по метрикам перезаписывала верифицированные
   параметры comp v3 (ratio ×1.3 по crest) — отключена для v3-пути.
8. Pre-read посылов падал (`get_send_level` отсутствовал, state-ключ
   `/level` вместо `/lvl`) — все посылы блокировались. Исправлено.
9. `AutoFXPlanner` использовал несуществующее имя модели `STEREO_DELAY`
   (официальное FW 3.1 — `ST-DL`).
10. Таблица посылов целилась в шины 1/2 (по конфигу — мониторные!);
    ретаргет на FX-шины планировщика 13/14/15. Имена шин на пульте
    пустые — мониторных шин в текущем зале нет (проверено readback).
11. Pan-preserve душил решение при центральной панораме (центр — не
    операторский выбор); phase-роль падала в unknown вместо preset.

## Наблюдения для следующей калибровки

- Trim kick гуляет между прогонами (−11 → +4.2 → −3.6): абсолютные
  open-loop цели зависят от музыкального материала в окне замера.
  Не храповик, но просится гистерезис/медиана по нескольким окнам.
- Пол канальной задержки WING = 0.5 мс (запись 0.1 → readback 0.5).
- OH-компрессия на одном из каналов не проходит верификацию
  (пампинг) — честный bypass; asymmetry OH L/R по материалу.
