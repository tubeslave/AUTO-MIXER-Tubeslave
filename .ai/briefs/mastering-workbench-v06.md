# Mastering Workbench v0.6: bounded candidate search

Generate causally distinct mastering candidates around the current Quality Master recipe.
Candidates change ONE major decision at a time: Clarity, Impact, clipping, Bass Director,
Stabilizer amount, or Maximizer drive.

Workflow:
premaster -> baseline recipe -> representative windows -> six causal candidates ->
level match -> Musical Regression Critic -> reject failures -> low-regression shortlist
(max 3) -> full render only finalists -> human level-matched A/B.

Important: low regression is NOT an automatic quality score. The engine may reject damage,
but it must not claim a subjective winner without listening evidence.
