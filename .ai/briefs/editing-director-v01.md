# Editing Director v0.1

Minimal-intervention editing before autonomous mixing.

The editor must preserve musical feel. It first checks sync/integrity, then multi-mic phase/polarity, local defects, transient/groove outliers, instrument timing relationships, vocal-double timing, and pitch. Pitch is diagnose-only in v0.1 until a reliable artifact-safe correction backend is validated.

Every accepted edit must preserve track length and pass regression. Global quantization is forbidden by default.
