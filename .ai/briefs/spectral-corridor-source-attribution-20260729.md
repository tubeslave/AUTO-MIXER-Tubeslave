# Бриф: спектральный коридор мастера + атрибуция источников (директива оператора 2026-07-29)

Источник: методика оператора «Алгоритм сведения по АЧХ» (ChatGPT-беседа,
передана 2026-07-29). Ядро: **мастер показывает проблему → группы
локализуют источник → каналы уточняют виновника → минимальное действие**.

## Что принять как правила проекта

1. **Спектральный коридор мастера, не линия.** 10 диагностических зон
   (Infrasonic 20–35 / Sub 35–60 / Low 60–120 / Upper bass 120–250 /
   Low mids 250–500 / Mids 500–1k / Upper mids 1–2k / Presence 2–5k /
   Brilliance 5–10k / Air 10–18k) с раздельными допусками
   (±1.5 дБ критическая середина, ±3 саб, ±4–5 верхняя октава).
   Ошибка: D_b = max(0, |E_b − T_b| − τ_b), взвешенная сумма w_b.
2. **Три уровня цели:** жанр → песня (референс/виртуальный саундчек/
   обучающий проход) → секция (verse/chorus/bridge — припев ЗАКОННО
   горячее в 80–150 и 1–4k; коридор per-section, не один на песню).
3. **Атрибуция вкладов:** C_i(f) = E_master(f) − E_master_without_i(f),
   оцениваемая математически (канальные спектры + роутинг + гейны +
   корреляция), НЕ мьютами и НЕ арифметической суммой FFT (фаза!).
   Ограничение канона: канальные USB-тапы pre-trim — вклад моделировать
   через известные тримы/фейдеры, замкнутый контур только Main 47/48.
4. **Порядок минимального действия:** ничего → автоматизация уровня →
   групповой баланс → малый EQ (сначала cut, ≤1–1.5 дБ, Q 0.5–2) →
   динамический EQ (только при временном маскировании) → компрессия
   (только по временной огибающей/crest, не по форме АЧХ) → сложное.
   Мастер-EQ — только proposal и только широкая коррекция.
5. **Лестница уверенности → полномочия:** 0.30 запрет действия /
   0.55 уведомление / 0.75 формирование proposal / 0.90 supervised
   apply. Реакция только на отклонение: сверх допуска + длительное +
   повторяющееся + с идентифицированным источником.
6. **Мульти-масштаб анализа:** 50–200 мс (транзиенты), 0.5–2 с
   (события), 5–15 с (фразы), секция (устойчивый баланс). Кратковременный
   удар вне коридора — не повод для коррекции.
7. **Цель инструмента — не кривая, а тройка:** допустимый рабочий
   диапазон + статистическая форма (медиана/границы/допустимые
   резонансы) + функция в текущем миксе.

## Чего нет (новая работа)

- A. Коридор как first-class конфиг: зоны, допуски, веса, per-genre /
  per-song / per-section профили (зона DSP + Codex для промоут-гейтов).
- B. Движок атрибуции C_i(f) с фазово-честной моделью суммирования
  (зона DSP; научная часть — корреляционная оценка вклада).
- C. Секционный детектор (intro/verse/chorus/…) или ручная разметка
  оператором как первый этап.
- D. Динамический EQ на группах от sidechain приоритетного источника
  (WING-реализуемость проверить: dyn-модели каналов/шин; иначе
  proposal-only оператору).
- E. Маппинг лестницы уверенности на существующие полномочия
  (0.90 = supervised apply — согласуется с текущим gated executor;
  зона Codex).

## Приоритет

После текущих Ф-фаз мастер-плана; сначала offline (в связке с CLD-0019 —
единый v3-тракт: коридор и атрибуция сначала доказываются на offline-
рендере), затем live-режим наблюдения, затем proposal, затем supervised.
