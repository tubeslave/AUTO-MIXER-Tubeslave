# Guided Mix Intake

Before autonomous mixing, Audio Workbench should ask only for musical intent that cannot be reliably inferred from audio.

Flow:
1. ingest/verify files and infer technical facts;
2. ask for 1–3 optional references and the exact domains liked in each;
3. ask section hierarchy;
4. ask macro-energy trajectory;
5. ask sectional space/depth trajectory;
6. ask mix-character priorities;
7. ask protected "do not break" properties;
8. optionally ask delivery/master target;
9. compile answers into MixIntent;
10. build Reference DNA, hierarchy, macro and space plans from MixIntent;
11. start experiments only when required intent is explicit.

Do not ask BPM/key/track count when confidently measurable. Unknowns stay unknown rather than guessed.
