# AWB-Q2: Context-aware causal mixing

Implement Roadmap Phase A: hierarchical song model, event-aware analysis and causal experiment engine.

Success criteria:
- hierarchy is explicit and validated;
- analysis can attribute measurements to hierarchy nodes;
- events are detected and summarized without quality judgments;
- every autonomous experiment has observation, hypothesis, expected effect, protected metrics and no-change control;
- source files remain immutable;
- unit tests cover synthetic hierarchy/events/causal gates;
- no new live-write path is introduced.
