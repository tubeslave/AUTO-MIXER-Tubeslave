# Объективная теория микса: конверты, решатель, валидация (утверждено оператором 2026-07-30)

Пакет из обсуждения оператора с надзорной Claude-сессией 2026-07-29/30.
Основание: философия оператора (память operator-mixing-philosophy, канал
CLD-0023) + методика спектрального коридора
(`.ai/briefs/spectral-corridor-source-attribution-20260729.md`, CLD-0020).
Интегральная самооценка метода: 82/100; лестница до 100 — §6.

## 1. Уточнённая философия (после критики)

Объективное ядро сведения — ОГРАНИЧЕНИЯ (коридор-плато, маскировка,
идентичность источника, crest-классы), внутри которых оптимизируется
ВНИМАНИЕ (касания кривой, салиентность «короля момента»). Цели не
постулируются — выучиваются из референсов и вердиктов оператора и остаются
его собственностью. Система мерит после каждого шага, действует минимально;
бездействие — действие по умолчанию. Система не просит доверия — она
предъявляет дистанцию восстановления.

## 2. Конверт источника (цель на инструмент)

- Спектральная половина: зоны касания (полосы, где источник обязан
  прикасаться к сумме) + identity-маска (ядро в ~6 дБ от максимума
  долгосрочного спектра по proximity-гейтированным окнам собственной
  активности; у маски свой confidence; маска видима/редактируема оператором).
- Динамическая половина: целевой crest по классу (стартовые прикидки:
  kick ≥14, вокал 8–10, бас 6–8 дБ — выучиваются, не константы).
- Микс сведён ⇔ сумма в коридоре ∧ каждый касается в своих зонах ∧
  каждый держит свой crest.

## 3. Решатель: подписи эффекторов + минимальное действие

Порядок по физике: (1) фаза/полярность/задержки и HPF/LPF — меняют сумму,
до любых балансовых замеров; (2) тримы к Ayaic-плоскостям; (3) канальный
EQ (только identity+гигиена; глубокий рез >3 дБ — только с ring-тестом
resonance_eq); (4) канальный комп к целевому crest (Ma2015);
(5) группа: внутренний баланс → glue → слот-EQ → фейдер группы;
(6) мастер: коридор+атрибуция → приказ вниз дешевейшему эффектору;
сам мастер — только tilt и glue.

Выбор эффектора по сломанному измерению: сумма плохая/части хорошие →
фаза; весь спектр не на месте → фейдер; форма → EQ; огибающая → комп;
мешает моментами → дин-EQ/sidechain. Двухспектровый замер (RMS-спектр vs
пик-спектр по полосам) различает гул (статический EQ) от бубнежа на
ударах (полосная динамика).

Инвариант сходимости (обязателен): каждое действие уменьшает суммарную
ошибку ≥X или откатывается с пометкой направления тупиковым; бюджет
действий на окно; повторный вход в тупик запрещён; все цели — абсолютные
идемпотентные (канон). EQ-бюджет: Σ|gain| ≤ ~6 дБ авто на канал; исчерпан
→ проблема не EQ-шная, вернуться к балансу.

## 4. Три этажа EQ

Канал = паспорт голоса (identity + гигиена, НЕ баланс; планировщик 6
WING-полос: 1-2 резонанса / 1-2 маскинг-реза / 1 тональная / 1 резерв
оператора). Группа = переговоры соседей (ERB-журнал маскировки;
комплементарные пары динамически от sidechain приоритетного источника;
слот группы проверяется против слот-профиля, НЕ против розовой кривой).
Мастер = арбитр (просыпается последним: отклонение устойчиво ∧ атрибуция
«размазано» (нет виновника >50%) ∧ коррекция широкая Q≤1 ≤2 дБ; главная
ручка — tilt).

## 5. Критика и фиксы (встроены в дизайн)

A. Кривая — необходимое, не достаточное → коридор-ПЛАТО (нулевой градиент
внутри допуска — запрет регрессии к среднему); оптимизируется салиентность
(partial loudness Мура—Глазберга — признанная модель, из нашей ERB-механики);
модели слуха — предфильтр, судья — оператор (слепые loudness-matched A/B).
B. Сцепленность эффекторов → мерить после каждого шага (K5), матрица
сцеплений для порядка, бюджет действий, «ничего не делать» дешевле мелкого
улучшения.
C. Неверные цели → identity по proximity-окнам + confidence + операторская
правка; целевые числа — профили из референсов/вердиктов (жанр→песня→секция);
blessed mix переписывает целевой профиль песни (вкус оператора — источник
целей, не система).
D. Реализуемость → атрибуция только на медленных масштабах; секции — из
маркеров Ableton-плейбека (экспорт сетки, синхронизация по Playback L/R);
сначала offline-прувер (CLD-0019).

## 6. Валидация и лестница до 100

- **Испытание восстановлением** (ключ): хороший микс ломается известным
  образом (грязь +4 @300, задавленный вокал, перекачанный glue, инверсия
  снейра...) → система чинит → метрика = дистанция восстановления до
  оригинала. Ground truth по построению, сотни тестов без слушателя.
- **Гигиена вердиктов**: слепые, loudness-matched, ключевые — с повтором;
  самопротиворечие на повторе = «безразличное измерение» → заморозка
  параметра (не учиться на шуме).
- **Санитарный слой входа** — первая стадия конвейера: клик-гард,
  клиппинг/дропаут/тишина, карантин канала (расширение CLD-0018).

Лестница (ворота — доказательства):
82 → 88: offline ≥90% дистанции восстановления, ≥3 мультитрека.
88 → 93: 3 цикла слепых A/B оператора — устойчивое «лучше».
93 → 97: саундчек на WING: кривые сходятся, 0 нарушений safety.
97 → 100: серия живых шоу: 0 заводок, коридор держится по секциям,
ручные вмешательства оператора убывают.

## 7. Зоны

двухспектровый замер, этажи EQ. Codex: инвариант сходимости как гейт,
CI-ворота лестницы, промоуты по воротам, атрибуция-гейт (>50% виновник).
Kimi: UI слепых A/B-вердиктов, маркеры секций (экспорт из Ableton),
индикаторы санитарного слоя, паспорт голоса в UI. Оператор: вердикты по
протоколу гигиены, правка identity-масок, blessed mix.
